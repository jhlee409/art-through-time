# Art Through Time

미술가, 작품, 미술 사조, 기법·용어, 주제-사건을 로컬 서버에서 관리하고 보는 학습용 앱입니다. 데이터는 로컬 JSON과 이미지 폴더에 저장하며, 관리자 모드에서만 추가·수정·삭제가 가능합니다.

## 빠른 실행

가장 쉬운 방법은 `Art_through_Time.cmd`를 더블클릭하는 것입니다.

- Node.js가 없으면 Windows Package Manager(`winget`)로 Node.js LTS 설치를 시도합니다.
- 이미 `4173` 포트에서 서버가 실행 중이면 새 서버를 띄우지 않고 기존 로그인 페이지를 엽니다.
- 새 서버를 띄울 때는 서버용 CLI 창을 숨김으로 실행하고 브라우저만 엽니다.
- 서버 로그는 `logs/art-atlas-server.out.log`, `logs/art-atlas-server.err.log`에 저장되며 새 서버를 띄울 때마다 이전 실행 로그를 덮어씁니다.
- 서버가 10초 안에 응답하지 않으면 브라우저를 열지 않고 최근 오류 로그를 표시합니다.

직접 실행:

```powershell
node server.js
# 또는
npm start
```

점검 실행(파일을 수정하지 않음):

```powershell
node tools/check-project-health.js
# 또는
npm test
```

브라우저 주소:

```text
http://localhost:4173/?login=1
```

## 로그인과 권한

- 관리자 로그인: 화가, 작품, 이미지, 기법, 사조 자료, 주제-사건을 추가·수정·삭제할 수 있습니다.
- 보기 모드: 자료 조회만 가능하며 저장이 필요한 기능은 사용할 수 없습니다.
- `.env` 파일이 없거나 로그인을 건너뛰면 보기 모드로 동작합니다.
- 관리자 모드는 한 세션만 유지됩니다. 새 창에서 다시 관리자로 로그인하면 이전 관리자 세션은 정리됩니다.
- 새 컴퓨터에서는 [`.env.example`](.env.example)을 `.env`로 복사한 뒤 관리자 이메일과 충분히 긴 고유 비밀번호를 설정합니다. `.env`는 Git에서 제외되므로 실제 값을 문서·변경 기록·채팅에 남기지 않습니다.

## 주요 화면

### 탭 이동 규칙

- 화가, 사조, 국가별 미술, 화가 리스트, 기법·용어, 주제-사건 탭 선택 버튼은 공통 동작을 사용합니다.
- 처음 로그인한 루트 화면은 `미술 사조의 이해`로 열고, 화가 및 작품 탭은 `?artists=1` 파라미터로 명시해 엽니다.
- 대상 탭이 이미 열려 있으면 새로 만들지 않고 그 탭으로 이동하되, URL이 요청 탭과 다르면 해당 URL로 다시 이동합니다.
- 대상 탭이 아직 열려 있지 않으면 이름이 지정된 새 탭으로 엽니다.
- `한 · u · 표` 표기 선택 상태는 탭 이동 시 URL query로 유지합니다.
- `화가 및 작품`은 `?artists=1`, 빈 사조 막대 연표인 `화가 리스트`는 `?artistList=1`로 열어 두 화면이 섞이지 않게 합니다.
- `화가 리스트` 탭은 기본으로 전체 국가의 1400~1950년 사조를 세로 방향으로 화면 맞춤값보다 1.68배 크게 보여주며, 가로 막대 영역 전체는 화면 안에 맞춰 가로 스크롤바 없이 표시합니다. 세로 스크롤로 전체 연표를 이동할 수 있고, 휠로 추가 확대하면 가로 스크롤도 사용할 수 있습니다. 왼쪽에서 여러 국가를 선택하면 시작 연도순으로 정렬하되, 같은 이름의 공통 사조는 합치고 국가별 세부 사조는 `미술 사조의 이해` 막대 기준에 따라 부모 사조 묶음 안에서 한 덩어리로 배치합니다. 사조명 행을 드래그하면 현재 화면에서만 순서를 임시로 바꿀 수 있습니다. 각 사조 막대 안에는 해당 국가·사조와 생애가 겹치는 화가를 생존기간 길이의 둥근 이름 박스로 패킹해 표시하고, 이름 박스를 누르면 해당 화가 연표가 열립니다. 국가는 화가의 주요 활동 지역 하나를 사용하고, 역사 국가명은 현재 국가명으로 정규화합니다. 생애 기간을 나타내는 가로 폭은 유지하되, 목록 안의 모든 이름 상자는 전체 화면에서 가장 낮은 이름 상자의 높이와 글꼴 크기를 공통 기준으로 사용합니다.
- 이 공통 이름 상자 높이·글꼴 규칙은 고정 요구사항이다. 이후 패킹·확대·레이아웃 변경에서도 행별 높이 보정, 개별 축소, 임의 확대를 다시 넣지 않으며, 수정 전후에 전체 사조 행의 상자 높이와 글꼴이 동일한지 확인한다.
- 이 탭에서 휠 확대는 화가 이름을 읽기 쉽게 하기 위해 기본 배율 이후 세로가 가로보다 더 빠르게 커집니다. 가로 최대 확대는 `2.25x`이고, 세로 확대 증가분은 이전 비균등 확대보다 3배 큽니다. 화가 이름 상자의 가로 생애 길이는 시간축의 출생·사망 좌표를 항상 그대로 따르고, 상자 높이·위치·상자 사이 간격·사조 상자 하단 여백은 사조 행의 세로 확대율과 같은 비율을 사용합니다. 글자는 가로·세로 같은 비율을 유지하며 각 이름 상자의 실제 높이 변화율과 같은 비율로 확대·축소합니다.

### 화가 목록과 연표

- 화가 연표에 작품 이미지를 추가하거나, 화가를 새로 등록하거나, 화가·작품의 이름·생몰년·주요 활동 지역·사조·작품 정보를 수정할 때는 같은 작업에서 화가 관계도와 화가 리스트를 함께 연쇄 갱신한다. 확인된 관계는 `data/artist-relations.json`에 만들거나 보충하되, 근거 없는 관계는 추정으로 추가하지 않는다.
- 위 변경 뒤에는 화가 리스트의 주요 활동 국가, 현재 국가명 정규화, 사조, 생몰년 및 사조 기간 매칭을 다시 확인한다. `regions`에는 확인된 활동 국가를 시간순으로 기록하고, 주요 활동 국가는 국적·출생국이 아니라 해당 사조의 대표작과 양식적 전환이 이루어진 제작 국가를 우선한다. 일반 활동 지역의 마지막 항목과 다르면 `movementActivityCountry`에 사조별 대표 활동 국가를 별도로 기록한다. 유효한 화가가 국가별 사조 행 부재로 빠지면 역사적 근거를 확인한 뒤 `data/art-movements.json`의 해당 국가·사조 행을 보강하고, 보강할 근거가 없으면 제외 사유를 기록한다.

- 왼쪽 목록에서 화가를 선택하면 대표작, 전체 작품, 시기별 연표를 볼 수 있습니다.
- 작품 연표 제목의 화가 이름을 누르면 같은 기본 화면 구성을 유지한 새 `화가 관계도` 탭이 열립니다. 가운데 화가를 기준으로 왼쪽은 연구·모사·학습한 선행 화가, 위는 스승, 오른쪽은 교류 화가(연한 하늘색), 아래는 대립·경쟁 화가(적색)로 표시합니다. 관계는 [`data/artist-relations.json`](data/artist-relations.json)의 화가 ID별 `study`, `teachers`, `exchanges`, `rivals` 배열에 검증 후 등록합니다. 배열 값은 화가 목록의 ID 또는 `{name:{ko,en}, wikipedia, agentAnswer}` 형태의 확인된 외부 인물로 쓸 수 있습니다. 등록 화가명은 화가 연표로, `wikipedia`가 있는 외부 인물은 해당 문서로 연결하며, 둘 다 없으면 `agentAnswer` 안내를 표시합니다. 확인되지 않은 관계는 표시하지 않습니다.
- 왼쪽 목록의 화가명은 한국어 모드에서 짧은 통용명, `u` 모드에서 성·이름 순, `표` 모드에서 국제 원어 표기를 사용합니다.
- 이름 정렬은 왼쪽 목록에 실제로 보이는 한국어 통용명을 기준으로 하며, `이름오름차순`, `이름내림차순`, `생년순`을 제공합니다.
- 목록 앞 국가 원형 아이콘은 같은 폭과 높이를 유지합니다.
- Firebase 내보내기 버튼은 화가 목록 화면에서 표시하지 않습니다. 서버의 마이그레이션 API와 관련 도구는 필요 시 사용할 수 있도록 보존합니다.
- Firebase 내보내기는 현재 운영 기능이 아닌 향후 데이터베이스 이관을 위한 준비 기능입니다. 로컬 JSON을 원본으로 유지하며, 실제 이관 전까지는 내보내기 결과를 외부 서비스에 자동 전송하지 않습니다.
- `그림 추가` 버튼은 파일 선택창을 바로 열며, 여러 이미지 파일을 동시에 선택할 수 있습니다. 이미지가 저장되면 해당 화가의 관계도·영향 사건 구조를 자동 점검하고, 출처 재확인이 필요한 역사 사건 검토 항목을 생성합니다.
- 여러 파일을 선택하면 작품 제목은 파일명에서 자동 추론하고, 연도 입력값이 없으면 파일명 안의 연도를 사용합니다.
- 사용자가 직접 추가한 작품은 `origin: "manual"`로 저장되며, 자동 갱신 과정에서 삭제하거나 덮어쓰지 않습니다.
- 모든 화가의 대표작 위에는 `화가 해설` 박스가 표시됩니다. 관리자는 `편집` 버튼으로 항목 수 제한 없이 불릿 해설을 쓰고 저장할 수 있고, 일반 사용자는 읽기만 할 수 있습니다.
- 화가의 `시기별 연표` 보기는 `18세기`처럼 세기 단위로 작품을 묶고, 세기 제목을 가운데 정렬합니다. 세기 섹션은 수평 경계선과 하나 건너 옅은 복숭아색 배경으로 구분합니다.
- 일반 작품 세로 연표도 왼쪽 축은 개별 연도 숫자 대신 세기 박스로 표시하고, 제작 연도는 작품 행 안쪽의 보조 표기로 남깁니다.

### 미술 사조

- `사조` 버튼 또는 `http://localhost:4173/?movementPopup=1`에서 별도 탭으로 열 수 있습니다.
- 사조 탭은 왼쪽 전용 사이드바(로고, `미술 사조의 이해` 제목, 제어 영역, 하단 로그아웃)와 오른쪽 비교 화면으로 구성합니다. 탭 이동 버튼은 오른쪽 위에만 둡니다.
- 사조 탭은 1400년 이후를 다룹니다.
- `1400년~1950년`은 국가별 사조 비교로 표시하고, `1950년~현대`는 `국제 현대미술` 공통 구간으로 표시합니다.
- 비교 국가는 프랑스, 독일, 오스트리아, 벨기에, 스위스, 네덜란드, 이탈리아, 영국, 스페인, 러시아, 노르웨이, 스웨덴, 덴마크, 그리스, 미국입니다. 기존에 전체 국가를 선택한 사용자의 화면에는 새로 추가된 국가도 자동 포함됩니다.
- 국가 선택은 왼쪽 사이드바에서 항상 펼쳐진 체크박스로 표시합니다. 개별 선택·해제와 전체 선택·해제를 지원합니다.
- 오른쪽 상단의 기간 선택 슬라이더 박스는 두지 않고, 사조 비교 영역은 전체 기간을 표시합니다.
- 오른쪽 사조 비교 영역은 화면 아래 끝까지 남은 세로 공간을 모두 사용합니다.
- 가로 드래그 중에도 사건 컬럼과 세기 표시 컬럼은 왼쪽에 고정해 항상 보이게 합니다. 세기 표시 컬럼은 이전 대비 80% 폭을 유지하고, 사건 컬럼은 한 줄 사건명에 맞춰 내부 왼쪽 여백을 최소화합니다.
- 표시 밀도 슬라이더는 두지 않습니다. 사조 비교 영역 위에서 마우스 휠을 굴리면 가로 폭은 유지한 채 세로 간격만 `0.5x~11.25x` 범위로 확대·축소하며, 휠 한 단계의 확대 계수는 `1.15배`입니다.
- 사조 비교 영역의 상하좌우 이동은 마우스 왼쪽 버튼 드래그로 합니다. 국가 제목 드래그 정렬, 사조 막대 더블클릭, 역사 사건 클릭은 기존 동작을 유지합니다.
- 세로축과 국가별 막대 배경은 `18세기` 같은 세기 박스, 수평 경계선, 하나 건너 옅은 복숭아색 배경으로 표시합니다.
- 국가 선택과 휠로 조절한 세로 확대값은 이전 선택값을 기본으로 유지합니다.
- 역사 사건은 `사회·정치`, `종교·사상`, `과학·경제`, `미술사` 중 하나를 선택해 표시하며 다른 분류는 숨깁니다. 왼쪽 사건 분류 버튼은 한 줄 4개로 표시합니다. 종교적 성격의 사건은 미술에 영향을 미쳤더라도 `종교·사상`으로 분류하고, 인쇄·과학·산업·철도·사진기·경제·우주과학·팬데믹 사건은 `과학·경제`로 분리합니다.
- 사조 탭에서 기간이 있는 역사 사건의 아래 연결선은 사건 이름의 첫 글자 아래에서 시작해 4px 굵기로 표시합니다. 화면 위에서 아래 순서로 검정·빨강·파랑·초록을 반복 적용해, 겹치는 기간선을 구분합니다.
- 사조 탭의 사건 라벨 수평 연결선은 세기 박스 내부로 들어가지 않고, 사건 컬럼과 세기 박스 사이의 왼쪽 여백까지만 표시합니다.
- 사조 탭의 사건 이름은 줄바꿈 없이 한 줄로 표시합니다. 사건 컬럼은 가장 긴 이름과 연결선 여백에 맞춰 계산해 내부 왼쪽 여백을 최소화합니다.
- `역사 사건 숨기기/보기`는 모든 사용자에게 제공하며, 관리자는 `역사 사건 추가`에서 사건 분류를 지정할 수 있습니다. 사건 라벨을 누르면 위키피디아 검색 결과가 새 탭에서 열립니다.
- 사조 막대를 더블클릭하면 해당 사조 설명이 새 탭에서 열립니다. 관리자 우클릭의 사조 설명 추가·교체·삭제 메뉴도 유지합니다.
- 사조 설명은 새 탭에서 열립니다. 관리자 모드에서는 이미지 카드 본문 오른쪽 위의 연필 아이콘으로 설명을 편집합니다. 설명은 줄 수 제한 없이 편집·저장할 수 있고 해당 사조 HTML 문서에 반영됩니다.
- `국가별 미술` 탭은 한 국가만 선택해 1400~1950년의 사조 변천을 넓은 단일 연표로 봅니다. 1950년 이후 국제 현대미술과 역사 사건 상자는 표시하지 않습니다.
- 이 탭의 작품 이미지는 해당 사조 설명 HTML의 마지막 심화 대표작 영역에 있는 카드만 직접 읽습니다. 앞부분의 비교·설명 도판은 가져오지 않으며, 카드의 문서 순서(국가·지역별 세부 전개 그리드 안의 순서)를 그대로 표시합니다. 같은 이미지가 여러 사조 설명 카드에 있으면 설명 본문이 가장 짧은 카드만 표시합니다.
- 카드 폭은 화면 폭의 약 1/14를 기준으로 하며 이미지는 자르지 않습니다. 사조 행과 막대 높이는 카드 전체가 보이도록 자동 산정합니다. 사조·연도 표기는 가운데 정렬하고, 사조 컬럼은 한글 약 두 글자만큼의 여유 폭을 둡니다.
- 이미지 카드가 있는 사조 막대를 더블클릭하면 원래 표시 막대보다 20% 큰 비모달 미리보기가 열립니다. 미리보기 안의 작품 카드에 마우스를 올리면 카드와 설명을 함께 최대 4배로 보는 돋보기가 막대 바깥의 가까운 여유 공간에 표시됩니다.
- 오른쪽 연표 영역은 상단 탭 이동 영역 아래부터 화면 바닥까지 사용하며, 탭 모음 끝에는 관리자용 전체 규칙 점검 버튼을 둡니다. 나라를 선택하면 모든 사조 행과 선택 기간이 모니터의 오른쪽 경계 안에 들어오는 기본 배율을 계산하고, 그 배율 때문에 오른쪽이 비지 않도록 시간축 폭을 자동으로 맞춥니다. 가로 스크롤은 사용자가 휠로 확대한 경우에만 생깁니다. 기간·표시 밀도 슬라이더는 이 탭에 두지 않습니다.
- 맨 위 시간축은 연도 숫자 대신 `18세기` 같은 세기 박스로 간략 표시합니다. 세기 라벨은 해당 영역 가운데 정렬하고, 경계 수직선과 하나 건너 옅은 복숭아색 배경으로 구분합니다. 막대 영역을 세로로 이동해도 이 세기 표기 줄은 상단에 고정합니다. 화가 리스트에서는 확대·축소해도 세기 박스 높이와 세기 글자 크기를 유지한다.
- 연표 위 휠은 커서가 놓인 지점을 중심으로 카드·사조 행·시간축을 같은 비율로 확대·축소하고, 왼쪽 버튼 드래그는 가로·세로 이동입니다. 마우스 오른쪽 버튼 메뉴의 `기본 비율로 보기`로 해당 국가의 기본 배율로 돌아갑니다.
- 국가별 미술 탭의 시간축 아래에는 해당 국가 미술에 영향을 준 사건 레일을 표시합니다. 처음 전체 보기에서는 사건 점과 핵심 라벨만 보이고, 확대하면 더 많은 사건명과 영향 설명이 보입니다. 사건을 누르면 연결된 위키피디아 문서가 새 탭에서 열립니다.
- 국가별 미술 사건은 사조 탭의 공통 역사 사건과 독립적으로 [`data/country-art-events.json`](data/country-art-events.json)에 저장합니다.
- 사건 중 미술사 영향이 큰 전쟁은 `eventKind: "war"`로 구분해 기간선 왼쪽에 이름을 표시합니다. 해당 국가 기준 승전은 붉은 굵은 실선, 패전은 초록 굵은 실선, 내전·복합전쟁처럼 판정이 어려운 사건은 검은 굵은 실선으로 표시합니다.
- 국가별 사조 막대의 원형 `!` 버튼은 해당 나라에서 그 사조가 태동한 배경 설명을 엽니다. 패널의 사건은 사조 시작 연도 기준으로 `태동 전 조건`과 `공식화·확산 사건`을 나누어 표시합니다. 설명 데이터는 사건 데이터와 독립된 [`data/country-movement-backgrounds.json`](data/country-movement-backgrounds.json)에 저장하고, 연결 사건은 국가별 사건 데이터의 ID로 참조합니다.
- 이 탭에서는 작품을 편집·추가·삭제하거나 이미지를 복사하지 않습니다. 국가·사조에 맞는 대표작 카드가 없으면 `대표작 자료 없음`으로 남기고, 보강은 사조 설명 문서에서 합니다. 사조 설명에서 카드 순서를 저장하면 열려 있는 국가별 미술 탭도 자동 갱신됩니다.
- 사조 설명의 대표작 모음은 `여러 국가에서의 전개` 표에 든 화가를 기준으로 구성합니다. 문서 상단에서 이미 도판으로 소개한 화가도 심화 대표작 카드에 다시 넣고, 표에 없는 화가·사조와 무관한 이미지는 넣지 않습니다.
- 심화 대표작 카드는 바로크 문서의 전체 폭 3열 카드 양식(이미지, `화가명, 《작품명》 · 사조` 제목, 연도·소장처 정보, 편집 가능한 설명)을 기준으로 합니다. 제목 위의 별도 화가 라벨과 제목 아래의 별도 `화가 사조` 줄은 사용하지 않습니다.
- 이 카드 표준은 서버의 사조 문서 저장·새로고침·제공 단계에서 자동 정규화됩니다. 따라서 이후 업로드하거나 만드는 사조 문서에도 같은 제목 형식, 오른쪽 위 편집 아이콘, 이미지 더블클릭 확대가 적용됩니다. 카드 이미지를 더블클릭하면 카드 표시 크기의 1.2배로 확대되고, 확대 이미지에서 다시 더블클릭하면 닫힙니다.

### 국가 전개 표와 심화 대표작 카드 운영 규칙

- `여러 국가에서의 전개` 표의 첫 열은 원칙적으로 `활동 지역 — 세부사조·지역 흐름` 형식으로 쓴다. 단, 고야처럼 특정 사조의 정식 화파가 아니라 선구인 경우에는 `스페인 — 낭만주의의 선구: 고야`처럼 관계를 명시한다.
- 표의 지역 행과 기존 설명·화가는 함부로 삭제하지 않는다. 분류를 정비할 때는 행 제목과 설명을 미술사적으로 맞추되, 기존에 다룬 화가를 반드시 보존한다.
- 표에 있는 **화가**는 문서 상단에 이미 도판이 있더라도 심화 대표작 카드에 다시 포함한다. 건축가·이론가처럼 화가 목록의 대상이 아닌 인물은 카드 대상에서 제외할 수 있다.
- 카드 배열은 국가 전개 표의 지역 순서를 따른다. 같은 지역·사조 안에서는 활동 시기 순서(초기 → 전성기 → 후기)로 배치한다.
- 관리자가 심화 대표작 카드의 순서를 바꿔 저장하면, 국가 전개 표의 같은 행에 있는 화가 링크 순서도 카드 순서에 맞춰 자동 갱신된다.
- 표의 화가가 화가 목록에 등록되어 있으면 표와 카드의 이름을 해당 화가 연표 링크로 연결한다. 동명이거나 유사한 이름을 다른 화가로 연결하지 않으며, 예: 안톤 라파엘 멩스를 르네상스의 라파엘로로 연결해서는 안 된다.
- 새 화가·대표작 카드를 보강할 때는 프로젝트 루트 `다운로드용/` 폴더의 기존 로컬 이미지 자산만 쓴다. 외부 이미지 URL을 새로 추가하거나 다운로드하지 않는다.
- 현재 이 원칙을 점검·반영한 문서는 르네상스, 매너리즘, 바로크, 로코코, 신고전주의, 낭만주의, 사실주의, 인상주의다. 인상주의의 경우 프랑스·미국·영국 인상주의와 하이델베르크파(호주 인상주의)를, 사실주의는 프랑스 사실주의·바르비종파와 이동파를, 낭만주의는 허드슨강 화파와 고야의 선구적 위치를 표기한다.

### 미술 기법 및 용어

- `기법·용어` 화면은 미술 기법과 전문 용어를 함께 다룹니다.
- 검색창에 입력하면 화가 목록처럼 즉시 필터링됩니다.
- 정렬은 작은 드롭다운 메뉴에서 선택합니다.
- 제목과 설명 사이의 세로 간격을 작게 유지해 첫 화면에서 설명 문단이 많이 보이도록 합니다.
- 이름·기법 표기는 왼쪽 사이드바의 고정 원형 선택기 `한 · u · 표`로만 전환합니다. 기본값은 `한`(한국어)이며, `u`는 번역된 한글에만 uHangul을 적용, `표`는 국제 원어 표기입니다. 별도의 `EN` 버튼·문서 내부 토글은 사용하지 않습니다.
- 관리자 모드에서는 용어 삭제, 설명 제목 옆 `+` 자료 링크 추가, 비교 기법 항목의 자료 링크 추가를 할 수 있습니다.
- 새 기법·용어를 추가할 때는 대표 이미지와 작품 설명을 `data/techniques/기법ID/` 아래 로컬 파일로 저장합니다.

### 주제-사건

- 주제-사건 목록은 왼쪽 사이드바에서 검색하고 선택합니다.
- `그림 추가`와 `모자이크 보기` 버튼은 이미지 갤러리 박스 안의 오른쪽 위에 표시합니다.
- `그림 추가` 버튼은 여러 이미지 파일 선택을 지원합니다.
- 여러 파일을 선택하면 제목은 파일명에서 자동 입력하고, 입력한 시작·끝 연도를 공통으로 적용해 순서대로 저장합니다.
- 주제-사건 화면에 올린 이미지는 외부 URL을 직접 참조하지 않고, 모두 `data/topic-images/`에 따로 저장한 뒤 그 경로를 사용합니다.

### 표기 선택기 표준

- 화면 본문의 중복 선택기는 만들지 않는다. 화가·기법·주제 화면은 왼쪽 사이드바의 선택기 하나가 전체 화면에 적용된다.
- 사조 설명 HTML은 독립 문서이므로 왼쪽 위에 고정된 원형 `한 · u · 표` 선택기 3개를 둔다. 기본값은 `한`(한국어)이고, 문서 안에서 선택한 값은 부모 화면의 사이드바 선택 상태와 동기화한다.
- 사조 제목은 위키피디아 링크로만 제공한다. 별도 `위키피디아` 고정 버튼은 만들지 않는다.
- 새 문서나 화면을 추가할 때도 이 표준 외의 언어·표기 전환 버튼을 추가하지 않는다.

## 탭별 자료 추가·편집 규칙

모든 저장 작업은 관리자 모드에서만 한다. 화면에 새로 표시하는 이미지는 프로젝트의 로컬 파일을 사용하며, 외부 이미지 URL을 새로 연결하지 않는다. 이미지 후보는 먼저 [`다운로드용/`](다운로드용/)에서 찾고, 파일이 없으면 `이미지 업로드 예정`으로 남긴다. URL에서 이미지 파일을 내려받아야 하는 예외는 대상 사이트·파일을 먼저 밝히고 사용자의 명시적 승인을 얻은 경우에만 처리한다. 코드·데이터·문서를 수정한 작업은 검증 뒤 `node tools/record-change.js`로 변경사항을 기록한다.

| 탭 | 추가·편집 위치 | 반드시 지킬 기준 |
| --- | --- | --- |
| 화가 | 화가 목록과 화가 연표 | 작품은 화가 데이터에 연결하고 로컬 썸네일·고해상도 경로를 사용한다. 사용자가 제공한 다운로드용 파일은 모두 확인·등록하며, 같은 작품의 새 파일은 기존 연결을 교체한다. 수동 추가 작품은 `origin: "manual"`을 유지하며 자동 정리로 덮어쓰지 않는다. 이미지 저장 뒤 관계도·영향 사건 자동 점검 결과를 확인하고, `pending-source-review` 항목은 검증 출처로 재검토한다. 화가 해설은 근거 있는 항목형 설명으로 작성한다. |
| 미술 사조 | 사조 설명 HTML과 사조 탭의 관리자 메뉴 | `여러 국가에서의 전개` 표의 화가와 마지막 심화 대표작 카드를 일치시킨다. 카드는 해당 국가·세부 사조의 특징을 가장 잘 설명하는 작품을 고르고, 교체 시 이미지·제목·연도·지역·설명을 함께 갱신한다. 카드에는 사조와 활동 지역을 표기하고, 지역·세부 전개별 독립 그리드 안에서만 순서를 바꾼다. 카드 순서는 국가별 미술 탭에 그대로 반영된다. 재사용 규칙이 바뀌면 [`작성규칙/사조html_작성규칙.md`](작성규칙/사조html_작성규칙.md)도 같은 작업에서 갱신한다. |
| 국가별 미술 | 직접 편집하지 않음 | 읽기 전용 화면이다. 카드·이미지·설명·순서는 연결된 사조 설명 문서의 마지막 심화 대표작 카드에서만 수정한다. 국가 판정은 카드의 활동 지역 표기를 우선하며, 기본 배율에서 오른쪽 모니터 경계를 넘는 가로 스크롤을 만들지 않는다. |
| 기법·용어 | 기법·용어 관리자 화면과 `data/techniques/` | 새 기법에는 공통 분류 필터 태그, 정의·설명, 실제 자료 링크를 넣고 현재 필터에서 보이는지 확인한다. 대표 이미지는 확인된 로컬 작품만 사용한다. |
| 주제-사건 | 주제-사건 관리자 화면과 `data/topics.json` | 작품 이미지는 `data/topic-images/`에 저장한 로컬 파일만 사용한다. 여러 작품을 추가할 때 제목·연도·표시 순서를 확인하고, 외부 이미지 URL만 남기지 않는다. |

### 국가별 사건·배경 데이터 운영

- 국가별 사건은 [`data/country-art-events.json`](data/country-art-events.json)에만 저장한다. 사조 탭의 공통 역사 사건과 섞지 않는다.
- 국가별 사조 배경 설명은 [`data/country-movement-backgrounds.json`](data/country-movement-backgrounds.json)에만 저장한다. 설명 파일은 사건을 복사하지 않고 `preludeEventIds`, `eventIds`로 국가별 사건 ID를 참조한다.
- `preludeEventIds`는 해당 나라의 사조 시작 연도 이전에 이미 존재한 조건만 넣는다. 예: 후원 구조, 종교·사상 변화, 도시화, 인쇄·산업·시장 변화, 이전 전쟁·정치 재편.
- `eventIds`는 사조가 이미 태동한 뒤 이름이 붙거나 공개 전시·선언·제도화·확산으로 드러난 사건을 넣는다. 중요한 사건이어도 시작 연도 이후라면 원인처럼 쓰지 않고 `공식화·확산 사건`으로 둔다.
- 한 사조 배경에는 시작 전 조건이 최소 1개 이상 있어야 한다. 이 기준은 `node tools/validate-country-art-data.js`로 검사한다.
- `thesis`는 단일 사건이 사조를 직접 만들었다고 쓰기보다, 여러 조건이 시각 방식과 후원·제도·시장 환경을 어떻게 바꾸었는지 설명한다.
- 사건의 `wiki`는 사건 이해를 돕는 텍스트 링크다. 이미지 URL이나 외부 이미지 의존을 새로 만들지 않는다.

### 사조 심화 카드 순서

- 심화 대표작 카드는 마지막 `.movement-enhancement` 안에서 국가·지역 세부 전개별 그리드로 구성한다.
- 관리자는 같은 그리드 안에서만 카드를 드래그해 순서를 바꿀 수 있다. 다른 세부 전개 그리드로의 이동은 허용하지 않는다.
- 저장된 HTML의 카드 순서가 국가별 미술의 해당 국가·사조 막대 순서다. 국가별 미술 탭에서 순서를 따로 편집하거나 연도순으로 재정렬하지 않는다.
- 이미 열려 있는 국가별 미술 탭은 사조 설명 저장 신호를 받으면 캐시와 열린 확대 미리보기를 정리하고 새 순서를 다시 불러온다.

## 새 화가 추가 절차

왼쪽 아래 새 화가 추가 `+` 버튼은 더 이상 사용하지 않습니다. 외부 이미지 자동 수집이 Wikimedia, 브라우저, 서버 요청 제한에 자주 걸리기 때문입니다.

새 화가를 추가할 때는 사용자가 먼저 작품 이미지를 다운로드 폴더에 저장합니다. 이후 작업 요청에서는 다운로드 폴더를 다시 언급하지 않아도 됩니다.

프로젝트에서 “다운로드 폴더”는 프로젝트 루트의 [`다운로드용/`](다운로드용/) 하나입니다. [data/local-image-sources.json](data/local-image-sources.json)도 이 폴더만 등록하며, 다른 컴퓨터의 OneDrive·사용자 경로는 탐색하지 않습니다.

Codex에는 화가의 이름, 국적, 사조만 제시하고 추가를 요청합니다. 위키피디아 주소를 따로 입력하지 않아도 됩니다.

Codex가 새 화가를 추가할 때 지켜야 할 기준:

- `다운로드용/`에서 작품 이미지 후보를 먼저 찾습니다. 파일이 있으면 로컬 파일만 연결하고, 외부에서 이미지를 받지 않습니다.
- 위키피디아/Wikidata는 원어명, 생몰년, 국가, 간단한 설명, 작품명, 출처 링크 같은 텍스트 정보 보충에만 사용합니다.
- 위키피디아, Wikimedia, 웹 검색, 외부 이미지 URL을 사용해 작품 이미지를 자동 검색하거나 자동 다운로드하지 않습니다.
- 새 화가 데이터에는 반드시 `artistSummary: { "ko": [], "en": [] }` 기본 필드를 둡니다.
- 이미지 파일명은 작품 제목을 알아볼 수 있게 저장하면 매칭이 쉬워집니다. 제목이 불명확한 파일은 Codex가 확인한 뒤 연결합니다.
- 이미지는 로컬 파일 저장과 고해상도 표시 저장 단계에서 10MB 이하 PNG로 축소 저장합니다. 변환이 끝난 대용량 원본은 보관하지 않습니다.
- 새 화가 추가 후에는 관리자 화면의 `전체 규칙 점검`을 실행합니다.

## 이미지 관리 원칙

- 화면에 직접 표시하는 이미지는 가능한 한 로컬 파일 경로를 사용합니다.
- 화가 작품 썸네일은 `data/thumbnails/`, 고해상도 이미지는 `data/high-resolution/`에 둡니다.
- 미술사조 HTML 이미지는 `data/미술사조/images/`에 두고, HTML 안에서는 `images/파일명.jpg` 형식으로 참조합니다.
- 기법·용어 이미지는 `data/techniques/`, 주제-사건 이미지는 `data/topic-images/`를 사용합니다.
- 주제-사건 이미지는 참조 URL만 남기지 않고 `data/topic-images/`에 복사해 보관합니다. 원본 출처는 필요하면 `sourcePage`, `sourceFile`로 따로 남깁니다.
- 사조 HTML과 표시 데이터에서는 외부 이미지 URL을 사용하지 않습니다. 사조 전용 이미지 폴더를 우선하되, 화가별 로컬 썸네일을 재사용할 때는 상대 경로와 고해상도 경로가 같은 로컬 자산을 가리키는지 검증합니다.
- 화가 작품 데이터에 과거 원본 `image` URL이 남아 있어도 화면 표시용 이미지로 사용하지 않습니다. 로컬 썸네일이나 로컬 고해상도 파일이 없으면 이미지를 표시하지 않습니다.
- 외부 URL, Wikipedia, Wikimedia, Openverse 등에서 이미지를 검색해 URL을 찾거나 내려받아 저장하는 자동화 코드는 삭제했습니다.
- 로컬 이미지 후보를 찾지 못한 작품은 잘못된 파일 경로를 유지하지 않고 `이미지 업로드 예정`으로 표시합니다.
- URL에서 이미지 파일을 찾아 다운로드하거나 URL 응답을 파일로 저장해야 하는 예외 상황은 반드시 사용자에게 먼저 허락을 받아야 합니다. 허락 없이 URL 이미지 파일을 다운로드하거나 외부 이미지 URL 의존을 새로 만들지 않습니다.
- URL 이미지 다운로드 스크립트를 새로 만들 때는 `tools/url-download-permission.js`의 승인 가드를 호출하고, `node tools/check-url-download-approval.js` 검사를 통과해야 합니다.

### 대기 이미지 확인·연결

이미지 파일을 다운로드 폴더에 넣은 뒤에는 아래 순서로 처리합니다.

```powershell
node tools/check-pending-local-images.js
node tools/import-pending-local-images.js
```

- 두 도구 모두 프로젝트 루트의 `다운로드용/`만 탐색합니다.
- 파일을 찾으면 가져오기 도구가 10MB 이하의 JPG, PNG, WebP, GIF를 `data/thumbnails/`로 복사하고 작품에 연결합니다.
- 파일이 없거나 10MB를 넘으면 외부 다운로드를 시도하지 않고 `이미지 업로드 예정` 상태를 유지합니다.

## 전체 규칙 점검

관리자로 로그인하면 화가 연표, 미술 사조, 미술 기법 및 용어, 주제-사건 화면 오른쪽 위에 `전체 규칙 점검` 버튼이 보입니다.

점검 내용:

- 화가 목록과 연표 제목의 한국어 표시 여부
- 한국어 통용명, uHangul 성·이름 순서, 국제 원어 표기의 분리 여부
- 화가 목록 이름 정렬이 실제 목록에 보이는 한국어 통용명 기준인지
- 네덜란드어 `van`의 한국어 표기를 `반`으로 통일했는지
- uHangul 폰트, 런타임, 화가 맵 연결
- uHangul 수동 변환 표식 필요 항목
- 썸네일 제목에 소장처 정보가 남아 있는지
- 국가 아이콘의 국가명 `title`, `aria-label` 연결
- 화가 목록 사조 필터의 대표 사조 누락, 중복, 작품별 사조 오매칭
- 화가 목록 다중 필터는 `연대 × 활동 지역 × 사조 × 세부사조·학파`의 독립 축이다. 같은 축의 복수 선택은 OR, 서로 다른 축은 AND로 결합하며, 선택값은 URL query에 유지한다. UI는 `주 활동 지역 → 사조 → 세부사조·학파 → 연대` 순으로 표시하고, 앞선 선택에 결과가 없는 값은 다음 필터에서 감춘다. taxonomy는 `data/art-taxonomy.json`, 화가별 배열 필드는 `periods`, `regions`, `movements`, `submovements`를 사용한다.
- 화가 목록의 앞쪽 국가 아이콘은 출생지의 현대 국가만 표시한다. 역사적 국가명은 아이콘에 병기하지 않으며, `regions` 필터는 출생국이 아니라 실제 주요 활동 지역을 사용한다.
- 사조 설명 문서의 하부 사조 기준 변경이 화가 목록, 화가 연표, 사조 설명 이미지 카드의 `화가 사조` 표시와 동기화되는지
- 이미지 누락, 제목 누락, QID 제목 잔류
- 로컬 이미지 파일이 10MB를 넘는지
- 미술사조 HTML 이미지 파일 누락 및 Git에 올리지 않는 이미지 폴더 직접 참조
- 기법·대표작·주제-사건 표시 데이터의 외부 이미지 URL, 캐시 폴더 직접 참조, 이미지 파일 누락
- 공개 이미지 없음 placeholder 처리
- 기법 설명 오른쪽 제목 옆 `+` 자료 버튼
- 비교 기법 항목의 링크 버튼과 저장 경로
- 국가별 미술 사건과 사조 배경 데이터의 국가·사조·사건 ID 참조, 위키 링크, 연도 범위
- 국가별 사조 배경의 `태동 전 조건`이 사조 시작 연도 이전 사건을 최소 1개 이상 포함하는지

점검은 수동 입력 작품, 직접 작성한 설명·이미지, 사용자가 선택한 대표작을 덮어쓰지 않습니다. 외부 웹에서 작품을 다시 수집하거나 삭제하지도 않습니다.

터미널에서 빠르게 확인할 때는 아래 명령을 사용합니다.

```bash
node --check app.js
node tools/validate-country-art-data.js
node tools/validate-movement-links.js
node tools/check-url-download-approval.js
node tools/check-pending-local-images.js
```

화가 연표 이미지와 관계도·역사 사건의 연결 상태만 재점검할 때는 다음을 사용합니다.

```bash
node tools/artist-relation-impact-audit.js --artist <artistId> --work <workId>
```

이 도구는 관계도·영향 사건의 구조와 출처 형식을 검사하고 `data/artist-relation-impact-audits.json`에 결과를 남깁니다. 역사 사실은 자동 추정하지 않으므로 `pending-source-review` 결과가 있으면 검증 출처를 확인한 뒤 직접 영향이 입증된 사건만 추가합니다.

보고서는 아래 형식으로 자동 저장됩니다.

```text
변경사항/규칙점검_YYYYMMDD_HHMM.md
```

다음 작업 세션에서는 이 보고서를 전달하거나 “가장 최근 규칙점검 보고서 확인해줘”라고 요청하면 됩니다.

## 변경사항 기록

코드, 데이터, 미술사조 HTML, README, 도구 스크립트를 수정한 뒤에는 날짜별 변경사항 문서에 작업 요약을 남깁니다. 직접 파일명을 계산하지 않고 아래 도구를 사용합니다.

```bash
node tools/record-change.js --section "섹션 이름" --item "변경 내용" --item "변경 내용"
```

- 도구는 Asia/Seoul 기준 날짜로 `변경사항/변경사항_YYYYMMDD.md`를 자동 생성하거나 기존 파일의 같은 섹션에 항목을 추가합니다.
- 같은 항목을 다시 실행하면 중복으로 추가하지 않습니다.
- Codex가 프로젝트 파일을 수정한 작업은 최종 검증 전에 이 도구로 변경사항을 기록해야 합니다.

주요 Git 관리 파일:

- `data/artists.json`: 화가와 작품 목록 원본
- `data/topics.json`: 주제-사건 데이터
- `data/techniques.json`: 기법·용어 데이터
- `data/country-art-events.json`: 국가별 미술 탭에 표시하는 각국 사건 데이터
- `data/country-movement-backgrounds.json`: 국가별 사조 발생 배경 설명과 연결 사건 ID 데이터
- `data/person-name-dictionary.json`: 인명 사전
- `uhangul/data/artist-map.json`: uHangul 화가 맵
- `data/generated/`: 과거 자동 조회 캐시 보관 폴더. 새 화가 추가나 화면 표시에서는 사용하지 않습니다.
- `data/미술사조/`: 미술 사조 설명 HTML

Git에 올리지 않는 로컬 폴더:

- `data/thumbnails/`
- `data/high-resolution/`
- `data/topic-images/`
- `data/backups/`
- `data/.image-staging/`
- `data/artist-relation-impact-audits.json`
- `logs/`
- `delivery/`
- `.env`

루트의 임시 서버 로그 `server.err.log`, `server.out.log`도 Git에서 제외합니다.

`data/thumbnails/`, `data/high-resolution/`, `data/topic-images/`는 컴퓨터에 따라 다른 로컬 저장 위치를 가리키는 Junction일 수 있습니다. 백업하거나 새 컴퓨터로 옮길 때는 Git 파일만 복사하지 말고 Junction 대상 폴더의 실제 이미지 파일도 함께 확인합니다.

## 작업과 동기화

코드, JSON 데이터, 생성 캐시, 미술 사조 HTML은 이 Git 저장소에서 관리합니다. 변경 후에는 필요한 파일을 확인한 뒤 `git add`, `git commit`, `git push`로 공유합니다.

이미지, 환경 설정, 로그, 배포 결과물은 Git에 올리지 않고 위 로컬 경로에 둡니다. 다른 컴퓨터에서 사용할 때는 Git 저장소를 따로 받은 뒤 프로젝트 안의 `다운로드용/` 폴더에 필요한 이미지 파일을 넣습니다.
