# 미술 사조 HTML 심화 보강 추적표

이 파일은 르네상스 방식의 심화 보강을 다른 사조 HTML에도 빠뜨리지 않고 이어가기 위한 작업표다.

## 적용 기준

- 별도 HTML로 만들지 않는 하위 화파와 지역 화파를 문서 안에서 충분히 설명한다.
- 국가별 전개는 후원 체계, 사회 조건, 매체 차이, 다음 사조와의 연결까지 쓴다.
- 이름이 등장하는 주요 화가는 가능한 한 대표작 한 점과 함께 설명한다.
- 마지막 대표작 카드는 문서 상단에서 이미 이미지로 제시된 화가와 작품을 반복하지 않는다.
- 새 이미지가 필요할 때는 `data/미술사조/images/`에 로컬 파일로 저장하고 HTML에는 상대 경로만 쓴다.
- 보강 후 `node tools/validate-movement-links.js`와 HTML 이미지 경로 검사를 실행한다.
