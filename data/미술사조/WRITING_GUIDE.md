# 미술사조 HTML 작성 규칙

새 미술 사조 HTML을 만들거나 기존 문서를 보강할 때는 다음 기준을 적용한다.

## 필수 구조

1. 사조의 핵심 개념과 역사적 배경을 설명한다.
2. 별도 HTML로 만들지 않을 하위 화파와 지역 화파를 충분히 설명한다.
   - 예: 르네상스 문서 안의 베네치아 화파, 바로크 문서 안의 카라바조주의와 볼로냐 고전주의.
3. 본문에 이름이 등장하는 주요 화가는 이름만 나열하지 않는다.
   - 해당 사조의 특징을 잘 보여주는 대표작 한 점을 반드시 붙인다.
   - 대표작은 기존 문서 초반부의 작품 카드와 같은 방식으로 이미지, 작가명, 작품명, 제작연도/소장처, 해설을 포함한다.
4. 국가별 전개를 따로 설명한다.
   - 중심 국가만 쓰지 말고, 그 사조가 다른 국가에서 어떤 사회적 조건과 후원 체계 속에서 변형되었는지 쓴다.
5. “상위 사조의 일부로 판단하여 별도 HTML을 만들지 않는 흐름”은 문서 안에서 명시한다.
   - 별도 문서가 필요한 독립 사조인지, 상위 문서 안의 하위 화파로 충분한지 구분한다.

## 대표작 카드 작성 기준

- 이미지는 가능하면 `data/미술사조/images/`의 로컬 이미지를 사용한다.
- 화가별 썸네일이 이미 있을 때는 `../thumbnails/<artist-id>/<file>` 상대 경로를 사용한다.
- 문서 앞부분에서 이미 도판으로 제시한 화가와 작품은 마지막 대표작 카드에서 반복하지 않는다.
- 마지막 대표작 카드는 표와 본문에는 등장하지만 아직 문서 위쪽에서 이미지로 확인하지 못한 화가를 우선한다.
- 설명은 작품 줄거리보다 “왜 이 작품이 해당 사조의 특징을 보여주는지”를 중심으로 쓴다.
- 작품 카드는 최소 3개 이상, 넓은 사조는 4개 이상 둔다.

## 보강 섹션 기준

기존 문서를 유지하면서 보강할 때는 다음 세 묶음을 포함한다.

- `따로 HTML로 나누지 않은 내부 화파`
- `국가별 발전 방식`
- `대표 화가와 대표작으로 확인하기`

현재 문서들은 `tools/enhance-movement-documents.js`로 이 기준을 일괄 적용한다.
