# 미술사조 HTML 작성 규칙

새 미술 사조 HTML을 만들거나 기존 문서를 보강할 때는 다음 기준을 적용한다.

## 필수 구조

1. 사조의 핵심 개념과 역사적 배경을 설명한다.
2. 별도 HTML로 만들지 않을 하위 화파와 지역 화파를 충분히 설명한다.
   - 예: 르네상스 문서 안의 베네치아 화파, 바로크 문서 안의 카라바조주의와 볼로냐 고전주의.
3. 본문에 이름이 등장하는 주요 화가는 이름만 나열하지 않는다.
   - 해당 사조의 특징을 잘 보여주는 대표작 한 점을 반드시 붙인다.
   - 대표작은 기존 문서 초반부의 작품 카드와 같은 방식으로 이미지, 작가명, 작품명, 제작연도/소장처, 해설을 포함한다.
4. 국가별 전개를 따로 설명한다.
   - 중심 국가만 쓰지 말고, 그 사조가 다른 국가에서 어떤 사회적 조건과 후원 체계 속에서 변형되었는지 쓴다.
5. “상위 사조의 일부로 판단하여 별도 HTML을 만들지 않는 흐름”은 문서 안에서 명시한다.
   - 별도 문서가 필요한 독립 사조인지, 상위 문서 안의 하위 화파로 충분한지 구분한다.

## 대표작 카드 작성 기준

- 이미지는 가능하면 `data/미술사조/images/`의 로컬 이미지를 사용하고, HTML 안에서는 `images/파일명.jpg`처럼 문서 기준 상대 경로로 참조한다.
- 외부 이미지 URL, `data/thumbnails/`, `data/high-resolution/` 직접 참조를 새로 만들지 않는다.
- 문서 앞부분에서 이미 도판으로 제시한 화가라도 `여러 국가에서의 전개` 표에 실명으로 등장하면 마지막 심화 대표작 카드에 다시 포함한다.
- 마지막 대표작 카드는 `여러 국가에서의 전개` 표에 실명으로 등장하는 화가·제작자를 기준으로 하며, 표에 없는 화가를 카드 수를 채우기 위해 추가하지 않는다.
- 설명은 작품 줄거리보다 “왜 이 작품이 해당 사조의 특징을 보여주는지”를 중심으로 쓴다.
- 작품 카드는 바로크 문서의 전체 폭 3열 카드 양식을 기준으로 한다.
- 카드 첫 줄은 `화가명, 《작품명》 · 사조 · 지역` 순서로 쓴다. 지역 앞에 `활동 지역:` 같은 접두어는 붙이지 않는다.
- 카드 제목의 화가명은 한 사람 이름이 중간에서 줄바꿈되어 두 사람처럼 보이지 않도록 묶는다.
- 로컬 이미지가 없으면 외부에서 다운로드하지 않고 이미지 없음 카드로 남긴다.

## 이름 표기 기준

- 화가 링크에는 `data-uh-korean`, `data-uh-display-korean`, `data-uh-list-korean`을 분리해 넣는다.
- `data-uh-korean`에는 정식 한국어 이름을 이름-성 순으로 쓴다. 예: `앙투안 바토`.
- `data-uh-display-korean`에는 uHangul 모드에서 보일 성-이름 순 표기를 쓴다. 예: `바토, 앙투안`.
- `data-uh-list-korean`과 링크의 기본 표시 텍스트에는 한국어 모드에서 보일 짧은 통용명 또는 성·별명을 쓴다. 예: `바토`.
- 단일명·별명 자체가 통용명인 화가는 억지로 성·이름을 나누지 않는다.

## 보강 섹션 기준

기존 문서를 유지하면서 보강할 때는 다음 세 묶음을 포함한다.

- `따로 HTML로 나누지 않은 내부 화파`
- `국가별 발전 방식`
- `대표 화가와 대표작으로 확인하기`

현재 문서들은 `tools/enhance-movement-documents.js`로 이 기준을 일괄 적용한다.
