uHangul v0.7 font is built locally from the single source of truth:
uhangul/spec/uhangul-v0.7.json.

Run the builder with a TrueType source font, for example:

python uhangul/font/build_uhangul_v07.py "C:\Fonts\UnDotum.ttf" "uhangul/assets/fonts/uHangul-v0.7.ttf" --fallback "C:\Fonts\UnBatang.ttf"

or from PowerShell:

python uhangul/font/validate_uhangul_v07.py `
  "uhangul/assets/fonts/uHangul-v0.7.ttf"

The final onset set is F, V, Z, R, X, and TH. TH /θ/ is the sole IPA
exception; all new consonants remain onset-only.
