uHangul v0.6-draft font is built locally from the single source of truth:
uhangul/spec/uhangul-v0.6-draft.json.

Run the installer with source font paths, for example:

python uhangul/font/build_uhangul_v06_draft.py "C:\Fonts\UnDotum.ttf" "uhangul/assets/fonts/uHangul-v0.6-draft.woff2" --fallback "C:\Fonts\UnBatang.ttf"

or from PowerShell:

python uhangul/font/validate_uhangul_v06_draft.py `
  "uhangul/assets/fonts/uHangul-v0.6-draft.woff2"

TH /θ/ is the sole IPA exception. It uses the Greek glyph θ in the onset
component; all new consonants remain onset-only.
