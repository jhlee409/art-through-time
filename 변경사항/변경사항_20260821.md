## 운영 방법

### 코드와 Git 추적 파일

`README.md`, `app.js`, `data/artists.json`, `data/generated/`, `data/미술사조/` 등 Git이 추적하는 파일을 수정한 뒤에는 다음 순서로 작업한다.

```powershell
git status
git add <확인한 파일 경로>
git commit -m "변경 내용"
git push
```

다른 컴퓨터에서 시작할 때는 새 작업 전에 `git pull`을 실행한다.

### OneDrive 전용 파일

이미지, `.env`, 로그, 백업, `delivery` 결과물은 연결된 OneDrive 경로에 저장된다. 파일 복사는 필요 없지만, 다른 컴퓨터에서 사용하기 전 OneDrive 동기화가 완료됐는지 확인한다.

### 새 컴퓨터 설정

Git 작업 폴더는 OneDrive 밖에 별도로 복제한다. 그 뒤 해당 컴퓨터의 OneDrive 데이터 폴더를 동일한 상대 경로로 연결해야 한다. 이 연결은 컴퓨터별 로컬 설정이므로 GitHub 푸시나 OneDrive 동기화만으로 자동 생성되지 않는다.

## 주의 사항

- OneDrive 데이터 전용 폴더에서 코드나 Git 메타데이터를 다시 관리하지 않는다.
- 추적 파일 변경은 `git push`만으로 다른 컴퓨터에 전달되지 않는다. 반드시 커밋한 뒤 푸시한다.
- 이미지·환경 파일은 GitHub에 푸시하지 않는다. OneDrive 동기화를 사용한다.
- `data/*.tmp`는 일시 파일이므로 공유 대상으로 보지 않는다.
- `delivery`는 OneDrive에서 읽기 전용 공유용 배포본을 보관한다. 브라우저에서 바로 이용할 공개 웹사이트는 별도 웹 호스팅이 필요할 수 있다.

- 메인 화가 화면의 `그림 추가` 버튼도 먼저 파일 선택 탐색창을 열고 여러 이미지 파일을 동시에 고를 수 있게 했다. 여러 파일은 파일명에서 작품 제목을 자동 추론하고, 연도 입력값이 비어 있으면 파일명 안의 연도를 찾아 각 작품을 차례대로 연표에 추가한다.
- 주제-사건 탭 오른쪽 위의 `그림 추가` 버튼을 앞의 `전체 규칙 점검` 버튼과 같은 높이, 글자 크기, padding 기준으로 맞췄다.
- 사조 탭의 `역사 사건 숨기기/보기` 버튼과 `역사 사건 추가` 버튼을 같은 높이, 글자 크기, padding, hover 형식으로 통일했다.
- 사조 탭의 기본 표시 기간을 `1200년~현대`로 바꾸고, `기간` 컨트롤에 시작·끝 연도 슬라이더를 추가했다. 슬라이더로 선택한 기간 전체가 화면 높이에 맞게 자동 재배율되므로, 기간을 좁히는 것이 곧 세로 확대 기능이 된다.
- 사조 탭에서 시작 연도가 1400년 이전이면 `중세 지역권` 체크박스를 추가로 표시한다. `이탈리아 도시국가`, `프랑스권`, `비잔틴권`, `북유럽권`, `이베리아권`, `영국권`을 선택할 수 있고, 1400년 이전 구간은 국가 대신 이 지역권 열로 묶어 보여준다.
- 1950년 이후의 현대 사조는 기존처럼 나라별로 나누지 않고 `국제 현대미술` 공통 구간으로 유지했다. 기존 마우스 휠 세로 확대는 기간 슬라이더와 역할이 겹치므로 제거했다.
- 사조 탭의 `중세 지역권` 선택 묶음을 현대 국가 선택 묶음 위에 배치했다. 기간 슬라이더는 잡고 움직이는 동안 화면을 다시 렌더링하지 않고 시작·끝 연도 표시만 갱신하며, 손을 떼면 선택 기간에 맞춰 차트를 다시 그리도록 바꿨다.
- 사조 탭의 `역사 사건 숨기기/보기`와 `역사 사건 추가` 버튼 묶음을 비교 설정 박스의 오른쪽 위로 이동했다.
- 사조 탭에서 `1100년~1800년`처럼 중세와 근세가 함께 포함된 기간을 선택하면 국가별 사조 막대가 중세 지역권 뒤로 밀려 보이지 않던 문제를 수정했다. 1400년 이후 국가별 막대가 있으면 국가 열을 먼저 배치하고, 중세 지역권 열은 그 뒤에 이어 보이도록 했다.
- 사조 탭에서 1400년 이전은 다루지 않는 것으로 최종 정리했다. 기간 슬라이더의 시작 최소값과 기본값을 모두 1400년으로 되돌리고, `중세 지역권` 체크박스와 1400년 이전 지역권 열 렌더링을 제거했다. 현재 사조 탭은 1400년 이후 국가별 사조와 1950년 이후 국제 현대미술 공통 구간만 표시한다.
- 사조 탭의 기간 슬라이더에서 `시작`·`끝` 글자를 제거하고, 시작 슬라이더와 끝 슬라이더를 한 줄 좌우 배치로 바꿨다. 두 슬라이더는 모두 `1400년~현대` 전체 범위를 쓰며, 한쪽이 최소 30년 간격을 넘기면 다른쪽 슬라이더가 함께 밀려 선택 기간을 유지한다.
- 사조 탭 기간 컨트롤의 왼쪽에 최저값 `1400`을 표시하고, 슬라이더 옆 개별 연도 표시를 제거했다. 아래 범위 표시 박스는 짧게 줄이고, 양쪽에 시작·끝 연도를 직접 입력할 수 있는 숫자 입력칸을 추가했다. 숫자 입력도 슬라이더와 같은 최소 30년 간격 보정 규칙을 사용한다.
- 사조 탭 기간 컨트롤의 오른쪽 슬라이더 끝에 `현재` 라벨을 추가하고, 아래 숫자 입력칸에는 각각 `시작입력`, `끝입력` 라벨을 표시해 기능을 알아보기 쉽게 했다.
- 사조 탭의 나라 선택 영역을 상단에 펼쳐진 체크박스 묶음 대신 `국가 선택 N개` 팝오버로 바꿨다. 팝오버 안에서 나라별 선택·해제, 여러 나라 선택, `전체 선택`, `전체 해제`를 할 수 있고, 선택 후에도 팝오버가 열린 상태로 유지된다. 사조 탭을 다시 열 때 시작·끝 연도와 국가 선택은 이전 선택값을 기본으로 유지한다.
- 사조 탭의 시작·끝 기간 슬라이더 가로 길이를 약 두 배로 키우고, 아래 가운데 선택 연도 박스 위에 `선택된 연도` 제목을 추가했다.
- 사조 탭에 `1x~3x` 범위의 `표시 밀도` 슬라이더를 추가했다. `1x`는 선택한 기간을 화면 높이에 맞추고, 값을 키우면 같은 기간의 세로 간격을 확대해 더 자세히 볼 수 있으며 필요한 경우 세로 스크롤로 이동한다. 표시 밀도 값도 이전 선택으로 저장된다.
- 사조 탭 `표시 밀도` 슬라이더의 최대 배율을 `3x`에서 `4x`로 높였다.

## 2026-08-21 현재 최종 상태 요약

- 모든 화가 연표는 `대표작` · `전체 작품` · `시기별 연표` 구성으로 통일했다. 체크 원으로 화가별 대표작을 저장하며, 대표작과 전체 작품은 각각 독립된 슬라이드쇼를 실행한다.
- 작품 카드는 왼쪽 위 대표작 체크, 왼쪽 아래 돋보기 호버 확대, 오른쪽 위 삭제, 오른쪽 아래 이미지 교체를 사용한다. 고해상도 작품은 Ⓗ로 표시되며 이미지를 더블클릭하면 화가명 · 작품명 · 연도 캡션이 있는 새 창으로 열린다.
- 슬라이드쇼는 화가명 · 작품명 · 연도를 왼쪽 아래 한 줄로 표시한다. 썸네일 제목은 작품명만 표시한다.
- 미술 기법 화면은 한국어 가나다순 오름/내림 정렬, 제목 아래 자동완성 검색, 절반 폭 사이드바를 사용한다. 표기 방식은 후속 표준화에 따라 왼쪽의 `한 · u · 표` 원형 선택기로 전환한다. 관리자 삭제는 오른쪽 `×`를 눌러 메뉴의 `삭제`를 선택해야 실행된다.
- 새 화가의 이미지 다운로드는 대표작·인지도 기준 상위 20개까지만 진행한다. 10MB 이상 이미지는 10MB 미만 PNG로 축소 저장하고, 기존 로컬 이미지는 보존한다.
