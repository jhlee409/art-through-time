## 운영 방법

### 코드와 Git 추적 파일

`README.md`, `app.js`, `data/artists.json`, `data/generated/`, `data/미술사조/` 등 Git이 추적하는 파일을 수정한 뒤에는 다음 순서로 작업한다.

```powershell
git status
git add <확인한 파일 경로>
git commit -m "변경 내용"
git push
```

다른 컴퓨터에서 시작할 때는 새 작업 전에 `git pull`을 실행한다.

### OneDrive 전용 파일

이미지, `.env`, 로그, 백업, `delivery` 결과물은 연결된 OneDrive 경로에 저장된다. 파일 복사는 필요 없지만, 다른 컴퓨터에서 사용하기 전 OneDrive 동기화가 완료됐는지 확인한다.

### 새 컴퓨터 설정

Git 작업 폴더는 OneDrive 밖에 별도로 복제한다. 그 뒤 해당 컴퓨터의 OneDrive 데이터 폴더를 동일한 상대 경로로 연결해야 한다. 이 연결은 컴퓨터별 로컬 설정이므로 GitHub 푸시나 OneDrive 동기화만으로 자동 생성되지 않는다.

## 주의 사항

- OneDrive 데이터 전용 폴더에서 코드나 Git 메타데이터를 다시 관리하지 않는다.
- 추적 파일 변경은 `git push`만으로 다른 컴퓨터에 전달되지 않는다. 반드시 커밋한 뒤 푸시한다.
- 이미지·환경 파일은 GitHub에 푸시하지 않는다. OneDrive 동기화를 사용한다.
- `data/*.tmp`는 일시 파일이므로 공유 대상으로 보지 않는다.
- `delivery`는 OneDrive에서 읽기 전용 공유용 배포본을 보관한다. 브라우저에서 바로 이용할 공개 웹사이트는 별도 웹 호스팅이 필요할 수 있다.
