- 메인 화가 화면의 `그림 추가` 버튼도 먼저 파일 선택 탐색창을 열고 여러 이미지 파일을 동시에 고를 수 있게 했다.
- 여러 파일은 파일명에서 작품 제목을 자동 추론하고, 연도 입력값이 비어 있으면 파일명 안의 연도를 찾아 각 작품을 차례대로 연표에 추가한다.

- 작품 선별 로직이 같은 `work.id`를 가진 항목을 제목+연도 차이 때문에 다른 작품으로 남기지 않도록 `app.js`, `server.js`, `tools/consolidate-generated-artists.js`에 중복 ID 방어를 추가했다.
- 화가 목록의 사조 드롭다운과 필터 매칭을 다시 점검했다. 기존에는 화가 대표 사조뿐 아니라 작품별 사조까지 모두 수집해 미켈란젤로처럼 작품 태그에 `매너리즘`이 섞인 화가가 매너리즘 필터에 포함되는 문제가 있었다.
- 사조 드롭다운과 필터는 화가의 대표 사조를 기준으로 동작하도록 정리하고, 대표 사조가 비어 있던 화가 13명의 `movement` 값을 보완했다. 이제 `매너리즘` 선택 시 `엘 그레코`, `야코포 다 폰토르모`만 표시된다.
- 사조 드롭다운 옵션은 라벨 정규화 기준으로 중복을 제거하도록 보완했다.
- 전체 규칙 점검에 화가 목록 사조 필터 확인 항목을 추가했다. 대표 사조 누락, 드롭다운 라벨 중복, 작품별 사조 태그가 화가 필터에 무조건 섞이는 코드, 매너리즘 필터에 미켈란젤로가 포함될 위험을 점검한다.
- 새 화가 `다 폰토르모, 야코포`를 추가했다. 위키 정보는 `https://en.wikipedia.org/wiki/Pontormo`를 기준으로 하고, 이미지는 지정된 `download` 폴더의 파일을 `data/thumbnails/artist-Q207929/`로 복사해 로컬 경로로 연결했다.
- 폰토르모에는 `방문`, `이집트의 요셉`, `베르툼누스와 포모나`, `엠마오의 저녁 식사`, `십자가에서 내려지는 그리스도`, `수태고지`, `아기 세례자 요한과 함께 있는 성모자`, `마리아 살비아티와 줄리아 데 메디치의 초상` 등 9개 작품을 등록했다.
- 폰토르모의 QID는 `Q207929`, 한국어 표시명은 `다 폰토르모, 야코포`, 사조는 `매너리즘`으로 정리했고 uHangul 맵과 이름 사전에 반영했다.
- `tools/consolidate-generated-artists.js`가 생성 데이터의 `movement`와 `aliases`를 새 화가 항목으로 가져오지 않던 문제를 보완했다. 앞으로 로컬 이미지 기반 새 화가를 추가할 때 사조 필터와 별칭 검색 정보가 함께 병합된다.
- 화가 이름 검색 박스를 왼쪽 절반 폭으로 줄이고, 오른쪽에 사조 선택 드롭다운과 `×` 해제 버튼을 추가했다.
- 사조를 선택하면 해당 사조에 속한 화가만 생년순으로 표시한다. `르네상스`는 이탈리아·북유럽·독일·플랑드르·베네치아·선르네상스 등 하위 르네상스 계열을 함께 포함하고, `북유럽 르네상스`, `독일 르네상스` 같은 하위 사조를 고르면 해당 범위만 좁혀 표시한다.
- `나의 화가 목록` 제목 옆에 전체 화가 수를 표시하도록 했다.
- 하단 `로그아웃` 버튼을 별도 줄에서 `EN` 버튼과 `FIREBASE 내보내기` 버튼 사이로 이동했다.
- 대표작 영역의 작품 카드를 드래그해 좌우 순서를 바꿀 수 있게 했다. 변경한 순서는 `featuredWorkIds`에 저장되어 다시 열어도 유지된다.

## 사조 탭

- 매너리즘 HTML의 `매너리즘 선구자들의 문제의식과 돌파` 설명을 르네상스의 성취 설명이 아니라 매너리즘 자체의 문제의식으로 수정했다. 완성된 르네상스 문법을 반복하지 않고, 인체 변형·불안정한 공간·인공적 색채·지적 알레고리로 돌파한 흐름이 드러나도록 정리했다.
- 매너리즘 문서 제목에 `르네상스`라는 단어가 함께 들어 있어 서버의 자동 `선구자들의 문제의식과 돌파` 삽입 로직이 르네상스 문구를 잘못 고르는 문제를 수정했다. 이제 제목에서 더 앞에 등장하는 사조명을 우선 매칭하므로 `매너리즘 — 르네상스의...` 제목에서는 매너리즘 문구가 삽입된다.
- 실행 중인 서버가 예전 삽입 로직을 쓰더라도 르네상스 문구가 다시 들어가지 않도록, 매너리즘 HTML 상단에 올바른 `data-art-atlas-pioneer-context` 박스를 직접 저장했다.
- `역사 사건 숨기기/보기` 버튼과 `역사 사건 추가` 버튼을 같은 높이, 글자 크기, padding, hover 형식으로 통일했다.
- `역사 사건 숨기기/보기`와 `역사 사건 추가` 버튼 묶음을 비교 설정 박스의 오른쪽 위로 이동했다.
- 1400년 이전은 사조 탭에서 다루지 않는 것으로 최종 정리했다. 기간 슬라이더의 시작 최소값과 기본값은 모두 1400년이며, 현재 사조 탭은 1400년 이후 국가별 사조와 1950년 이후 국제 현대미술 공통 구간만 표시한다.
- 기간 슬라이더에서 `시작`·`끝` 글자를 제거하고, 시작 슬라이더와 끝 슬라이더를 한 줄 좌우 배치로 바꿨다.
- 두 슬라이더는 모두 `1400년~현대` 전체 범위를 쓰며, 한쪽이 최소 30년 간격을 넘기면 다른쪽 슬라이더가 함께 밀려 선택 기간을 유지한다.
- 기간 컨트롤의 왼쪽에 최저값 `1400`, 오른쪽에 `현재` 라벨을 표시했다.
- 아래 숫자 입력칸에는 각각 `시작입력`, `끝입력` 라벨을 표시하고, 가운데 선택 연도 박스 위에는 `선택된 연도` 제목을 추가했다.
- 아래 범위 표시 박스는 짧게 줄이고, 양쪽에 시작·끝 연도를 직접 입력할 수 있는 숫자 입력칸을 추가했다. 숫자 입력도 슬라이더와 같은 최소 30년 간격 보정 규칙을 사용한다.
- 나라 선택 영역을 상단에 펼쳐진 체크박스 묶음 대신 `국가 선택 N개` 팝오버로 바꿨다.
- 팝오버 안에서 나라별 선택·해제, 여러 나라 선택, `전체 선택`, `전체 해제`를 할 수 있고, 선택 후에도 팝오버가 열린 상태로 유지된다.
- 사조 탭을 다시 열 때 시작·끝 연도와 국가 선택은 이전 선택값을 기본으로 유지한다.
- 시작·끝 기간 슬라이더 가로 길이를 약 두 배로 키웠다.
- `1x~4x` 범위의 `표시 밀도` 슬라이더를 추가했다. `1x`는 선택한 기간을 화면 높이에 맞추고, 값을 키우면 같은 기간의 세로 간격을 확대해 더 자세히 볼 수 있으며 필요한 경우 세로 스크롤로 이동한다.
- 표시 밀도 값도 이전 선택으로 저장된다.

## 참고

- 1200년 이전 또는 1400년 이전 중세 지역권 표시를 검토했지만, 최종 방향은 1400년 이전을 사조 탭에서 다루지 않는 것으로 정리했다.
- 오류·버그·충돌 우려 점검을 수행했다. `app.js`, `topics.js`, `techniques.js`, `rules-check.js`, `server.js` 문법 검사와 주요 JSON 파일 파싱을 확인했다.
- 프로젝트 재점검에서 마사초의 `generated.file`이 없는 `data/generated/qid-Q5811.json`을 가리키던 문제를 실제 존재하는 `data/generated/artist-url-1787307872488.json`으로 보정했다.
- 전체 HTML·JSON 표시 이미지 경로를 다시 점검해 로컬 표시 이미지 파일 누락이 0개임을 확인했다. 화가 작품 186점은 외부 URL 의존 상태로 남아 있으며, 이는 기존 `URL 의존` 배지로 표시된다.
- 외부 URL 의존 화가 작품 186점의 로컬화를 시도했다. Wikimedia 요청 제한으로 8점만 `data/thumbnails/` 로컬 파일로 저장했고, 실패한 178점은 기존 외부 URL을 유지해 화면에 `URL 의존` 배지가 계속 표시되도록 했다.
- 로컬화 시도 결과와 실패 목록은 `data/external-image-localization-report.json`에 저장했다.
- 재시도용 보조 스크립트 `tools/localize-external-artist-images.js`를 추가했다. 성공한 작품만 로컬 경로로 바꾸고 실패한 작품은 기존 URL 의존 상태로 남기도록 했다.
- README에 외부 URL 이미지 자동 로컬화 방식, 실패 시 `URL 의존` 유지 원칙, 실패 보고서 위치를 추가했다.
- 사조 탭 기간 입력 보정 코드에서 `시작입력`과 시작 슬라이더의 최종 최소 간격 보정 조건을 일관되게 정리했다.
- 사조 탭의 예전 휠 확대용 미사용 함수와 주제-사건 탭의 예전 유사도 검색용 미사용 함수를 제거했다.
- 더 이상 사용하지 않는 `.atlas-period`, `.atlas-country-option-all` CSS와 루트 서버 로그 파일 추적 가능성을 정리했다. `server.err.log`, `server.out.log`는 `.gitignore`에 추가했다.
