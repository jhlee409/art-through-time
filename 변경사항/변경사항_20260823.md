# 변경사항 2026-08-23

## 화가 목록 사조 필터

- 화가 목록의 사조 필터를 접기/펼치기 가능한 드롭다운으로 바꿨다. 하부 사조가 여러 개인 대분류는 아래/위 화살표로 펼치고 접을 수 있으며, 하부 사조를 선택한 상태에서는 해당 대분류가 자동으로 펼쳐진다.
- 드롭다운 목록 폭과 기본 필터 버튼의 화살표 크기를 조정했고, 필터 해제 `x` 버튼과 화살표가 겹치지 않도록 간격을 벌렸다.

## 미술사조 설명 문서

- 사조 설명 문서의 작품 이미지 카드에 `화가 사조` 정보를 자동으로 표시하도록 했다. 세부 사조가 있는 경우 `피렌체·로마 매너리즘 - 매너리즘`, `베네치아 화파 - 르네상스`처럼 하부 사조와 상부 사조를 함께 보여준다.
- 대표작 카드의 첫 라벨이 화가 이름만 반복하는 경우 자동으로 제거한다. `네덜란드 매너리즘 · 하를럼`, `베네치아 후기 르네상스 · 전환 사례`처럼 해석에 필요한 라벨은 유지한다.

## 미술 기법 및 용어

- 새 기법 항목 `프레스테차(Prestezza)`를 추가했다.
- 대표작은 틴토레토의 《노예의 기적》(1548)으로 등록했다. 빠른 실행, 열린 붓질, 극적인 사선과 명암이 프레스테차를 설명하기에 적합하기 때문이다.
- 대표 이미지는 Wikimedia Commons 공개 이미지를 `data/techniques/prestezza/tintoretto-miracle-of-the-slave.jpg`로 저장해 로컬 경로로 연결했다.

## 전체 규칙 점검

- 전체 규칙 점검에 `사조 분류 동기화 확인 항목`을 추가했다.
- 이 항목은 사조 설명 문서에서 하부 사조 기준이 계속 바뀔 때, 같은 기준이 화가 목록 필터, 화가 연표 상단 사조 표시, 사조 설명 이미지 카드의 `화가 사조` 표시에도 함께 반영되는지 확인한다.
- 앱 쪽 `artistMovementDisplayRules`와 서버 쪽 `serverArtistMovementDisplayRules`, 화가별 QID override 목록이 어긋나면 규칙점검 보고서에 표시된다.

## README

- `프레스테차(Prestezza)` 추가 기준과 대표 이미지 저장 위치를 README의 미술 기법 및 용어 설명에 반영했다.
- 전체 규칙 점검 설명에 화가 목록 사조 필터 점검과 사조 분류 동기화 점검을 추가했다.

- README 구조를 빠른 실행, 주요 화면, 새 화가 추가 절차, 이미지 관리 원칙, 규칙 점검, 변경사항 기록, 데이터 저장 위치 순서로 재정리했다.
- 새 화가 artistSummary 필수 규칙, URL 이미지 다운로드 허가 규칙, record-change 변경사항 기록 규칙을 유지하면서 중복 설명을 줄였다.

## 프로젝트 점검 및 데이터 정리

- 이미지 점검 로직이 외부 work.image URL을 이미지 있음으로 오판하지 않도록 로컬 thumbnail 또는 highResImage만 인정하게 했다.
- 모든 기존 화가에 artistSummary 기본 필드를 추가해 화가 해설 박스 규칙과 원본 데이터 구조를 맞췄다.
- 프리마티초의 깨진 사조명, 카라바조 작품의 한국어 사조명, 생몰연대 밖 작품 연도 19건을 정리했다.
- 점검 결과를 재실행 가능한 tools/apply-audit-fixes.js 스크립트로 남겼다.

## 변경사항 기록 자동화

- tools/record-change.js를 추가해 날짜별 변경사항 문서를 자동 생성하고 섹션별 항목을 중복 없이 추가할 수 있게 했다.
- README에 프로젝트 수정 후 record-change 도구로 변경사항을 기록하도록 작업 규칙을 추가했다.

- 기존 섹션에 항목을 추가할 때 다음 제목 앞에 빈 줄을 유지하도록 record-change 도구의 Markdown 포맷 처리를 보정했다.

## 표기 확인

- 수르바란 표기는 스페인어 Zurbarán의 z를 한국어에서 ㅅ 계열로 옮기는 관례에 맞으므로 주르바란/주루바란이 아니라 수르바란으로 유지하기로 확인했다.

## uHangul 표기

- 스페인어 Zurbarán의 z가 영어식 Z로 표시되던 문제를 고쳐 수르바란 uHangul 표기를 [Zㅜ]가 아니라 [THㅜ] 기준으로 생성하게 했다.
- Francisco de Zurbarán과 Juan de Zurbarán 예외를 uHangul 생성 규칙에 추가하고 artist-map 및 person-name-dictionary를 다시 생성했다.
