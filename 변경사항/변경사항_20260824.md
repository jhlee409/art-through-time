## 사조 설명 열기

- 사조 설명 페이지를 오른쪽 상세 패널 대신 항상 새 탭으로 열고, 관리자 이미지 카드 설명 편집 기능도 새 탭에서 사용할 수 있게 했다.

- 새 탭의 초기 빈 문서 로드에서 편집기 연결이 소모되지 않도록, 이미지 카드가 있는 실제 사조 문서가 로드된 뒤에만 편집기를 연결하도록 보정했다.

- 새 탭이 문서로 이동하는 동안에도 편집기를 반복 연결해, 실제 이미지 카드가 준비된 뒤 편집 버튼이 표시되도록 보완했다.

- 바로크 대표작 카드에 카라바조 《성 마태오의 소명》, 아르테미시아 《홀로페르네스의 목을 베는 유디트》, 안니발레 카라치 《바쿠스와 아리아드네의 승리》를 기존 로컬 이미지로 추가하고 생략 안내 문구를 제거했다.

- 바로크 대표작 목록은 국가별 전개 표의 카라바조·카라치·베르니니·루벤스·반 다이크·렘브란트·베르메르·프란스 할스·벨라스케스·수르바란·무리요·푸생·클로드 로랭·샤를 르 브룅을 모두 포함하도록 확인했다.

## 사조 대표작 표-카드 통일

- 여러 국가에서의 전개 표를 가진 사조 설명 19개 문서에서, 표의 화가만 표 순서대로 대표작 카드로 재구성하도록 공통 보강을 추가했다.
- 심화 대표작 카드는 바로크 문서와 같은 2열 그리드, 카드 여백, 이미지 영역, 본문 간격으로 통일했다.
- 기존 카드의 설명·이미지를 재사용하고, 본문에 로컬 도판이 없는 경우에는 다른 화가 그림을 대신 넣지 않도록 처리했다.

- 표 기준으로 카드를 재배열하거나 숨기던 공통 보강을 19개 문서에서 제거해, 바로크의 기존 심화 대표작 구성과 순서를 복구했다.
- 다른 사조 문서는 대표작 카드의 내용·순서를 바꾸지 않고, 바로크 원본과 같은 3열 격자·이미지 영역·카드 여백만 적용했다.

- 르네상스를 포함한 사조 심화 대표작 목록에서 카드를 감싸던 enhancement-panel을 풀어, 바로크처럼 본문 전체 폭을 사용하도록 수정했다.
- 바로크 원본은 변경하지 않았고, 다른 사조의 대표작 카드는 바로크와 같은 3열 전체 폭 카드 레이아웃을 적용했다.

- 심화 카드가 .wrap 안에 있는 사조 문서에서는 카드 그리드를 100vw로 확장해, 바로크처럼 모니터 가로 폭 전체를 사용하도록 보완했다.

- 대표작 카드 원칙을 작업 규칙과 README에 명시했다: 국가별 전개 표의 화가는 앞에서 이미 나온 경우에도 모두 다시 넣고, 표 밖 화가나 다른 사조 이미지는 넣지 않는다.
- 대표작 카드는 바로크의 전체 폭 3열 카드 양식을 기준으로 유지한다.

- Renaissance 기본 설명 문서의 심화 대표작에 마사초·라파엘로·티치아노·얀 반 에이크를 기존 로컬 도판과 함께 추가하고, 앞에서 나온 화가를 제외한다는 안내를 표의 대표 화가를 다시 비교한다는 안내로 교체했다.
