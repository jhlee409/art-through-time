# 2026-08-25 변경 사항 — 표기 선택기 표준화

- 이름과 기법의 표시 방식은 `한 · u · 표`로 통일했다. `한`은 한국어(번역이 없으면 국제 원어), `u`는 한국어 번역이 있을 때만 uHangul, `표`는 국제 원어 표기다.
- 화가·기법·주제 화면은 왼쪽 사이드바의 고정 원형 선택기 하나만 사용하며, 오른쪽 본문의 중복 선택기는 제거했다.
- 사조 설명 HTML은 독립 문서이므로 왼쪽 위에 고정 원형 선택기 3개를 자동 주입한다. 이 선택은 부모 화면과 동기화한다.
- 이전 모서리 단일 `u` 버튼, 한국어/EN 토글, 문서 내부의 이전 도구막대, 오른쪽 위 위키피디아 고정 버튼을 폐기했다. 사조 제목의 위키피디아 링크만 유지한다.
- 서버 시작 시 모든 저장된 사조 HTML을 점검하여 이전 제어 흔적을 제거하고 현재 표준 도구막대를 다시 주입한다.
- 사조 링크·JSON 계약·uHangul 표기·다운로드 승인 규칙을 재점검했다. 등록되지 않은 화가 ID를 가리키던 사실주의 문서 링크 3개는 일반 텍스트로 보정했으며, 사조 문서 링크 검사 결과는 누락 대상·외부 이미지·중첩 링크 모두 0건이다.

## 로컬 이미지·세션 규칙

- 다운로드 폴더 후보를 OneDrive 루트 기준으로 자동 탐색하는 공통 설정과 점검 도구를 추가했다.
- 누락된 낭만주의 대표작 3점은 외부 다운로드 없이 이미지 업로드 예정 상태로 표시하도록 정리했다.
- 로그아웃 시 서버 프로세스를 종료하지 않고 관리자 세션만 해제하도록 수정했다.

- 로컬 파일을 찾으면 10MB 이하 이미지를 썸네일 폴더에 자동 연결하는 대기 이미지 가져오기 도구를 추가했다.

## 바로크 사조 문서

- 푸생 대표작 카드를 《아르카디아에도 나는 있다》에서 《게르마니쿠스의 죽음》으로 교체하고 기존 로컬 이미지를 사조 이미지 폴더에 복사했다.


- 샤를 르브룅 대표작 카드를 루이 14세 치하의 프랑스 궁정 바로크를 드러내는 《루이 14세의 신격화》로 교체하고 화가 연표 링크를 연결했다.

- 르브룅 대표작 카드의 작품명을 《루이 14세의 신격화(승천)》으로 병기했다.

- 프랑스 바로크 대표 화가 명단과 하단 대표작 카드에 야생트 리고와 《루이 14세의 초상》을 추가했다.

## 사조 대표작 카드 표기

- 모든 사조 HTML의 심화 대표작 카드 첫 줄에 사조 뒤 활동 지역을 표기하도록 적용했다.
- 화가 데이터에 활동 지역이 없는 카드 266개는 임의 추정 대신 활동 지역 확인 필요로 표시했다.
- 활동 지역 표준과 자동 변환 도구를 사조 작성규칙에 추가했다.

- 활동 지역 접두어를 제거해 국가·지역명만 보이도록 모든 사조 HTML을 갱신하고, 바로크 사조 태그와 동일한 글꼴 크기·색을 적용했다.

## 클로드 로랭 연표

- 지정 다운로드 폴더의 기존 로컬 이미지 6개를 연결해 클로드 로랭의 연표 작품을 1점에서 6점으로 확장했다. 외부 이미지 다운로드는 하지 않았다.

## 서버 안정성

- JSON API 요청 본문을 공통 reader로 처리해 12MB 초과 chunked 요청도 413 JSON 응답으로 한 번만 반환하도록 정리했다.
- 관리자 세션 idle 만료 시간을 90초에서 10분으로 늘려 긴 편집 중 보기 모드로 전환되는 가능성을 줄였다.

## 로컬 이미지 경로

- 다운로드 폴더 후보에 Windows 백슬래시 표기의 OneDrive Art_through_Time download 경로를 명시적으로 추가했다.

## 화가 목록

- 샤를 르브룅을 프랑스 바로크 화가로 추가하고 다운로드 폴더의 기존 로컬 이미지 9점을 작품으로 연결했다.
- 샤를 르브룅의 화가 해설, 프랑스 바로크 필터, uHangul 화가 맵과 인명 사전을 갱신했다.

- 야생트 리고를 스페인 제국령 카탈루냐(페르피냥) 출생, 프랑스 활동의 바로크 화가로 추가하고 다운로드 폴더의 기존 《루이 14세의 초상》 이미지를 대표작으로 연결했다.
