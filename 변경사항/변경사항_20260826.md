# 변경사항 2026-08-26


- 대표작 카드를 화면 폭의 1/15 너비로 통일하고, 이미지는 object-fit: contain으로 잘림 없이 표시하도록 조정했다.
- 같은 이미지가 여러 사조 설명 카드에서 발견되면 설명 본문 길이가 가장 짧은 카드만 국가별 미술 연표에 표시하도록 중복을 제거했다.

- 대표작 추출 범위를 사조 설명 문서의 마지막 심화 대표작 영역으로 제한해, 앞부분의 비교·설명 도판이 국가별 미술 연표에 섞이지 않도록 했다.

- 대표작 카드 폭을 화면 폭의 1/14로 조정했다.
- 사조 막대의 높이가 대표작 카드 전체 표시 높이에 못 미치면 이미지 카드를 숨기고 기간·표시 밀도 조절 안내만 보이도록 해, 잘린 이미지를 표시하지 않게 했다.

- 대표작 카드가 잘리지 않도록 카드가 있는 사조 막대의 기간 길이를 기준으로 필요한 세로 표시 밀도를 자동 계산하고, 연표 높이를 확대해 세로 스크롤로 모든 카드를 표시하도록 바꿨다.

- 사조 막대를 시작 연도순으로 왼쪽에서 오른쪽으로 한 칸씩 배치하고, 넘치는 폭은 연표 전체의 가로 스크롤로 보도록 변경했다.
- 국가별 미술의 표시 밀도를 1/4~1 축소 배율로 바꾸고, 밀도 슬라이더를 더블클릭하면 1로 되돌리도록 했다. 대표작 카드 자동 맞춤은 모든 축소 단계에서 카드가 잘리지 않게 유지한다.

- 각 사조 막대의 가로 폭을 대표작 카드 3장과 간격·여백이 한 줄에 들어가는 크기로 확장했다.

- 표시 밀도 1의 기준을 선택 기간과 무관하게 화면 세로 100년으로 고정했다. 1/4에서는 약 400년이 보이며, 긴 기간은 세로 스크롤로 이어진다.

- 연표 축을 전환해 사조를 시작 연도순으로 세로 행에 배치하고, 시간을 가로축으로 표시하도록 바꿨다. 표시 밀도 1은 화면 가로 150년, 1/4는 약 600년 기준이다.

- 가로 시간축의 표시 밀도 1 기준을 화면 가로 300년으로 넓혔다.
- 대표작 카드 크기를 기존의 80%로 줄이고, 사조 행과 막대 높이를 이미지 카드 전체 높이에 맞췄다.

- 대표작 카드의 최대 높이를 고정하고 사조 행·막대 높이를 그 카드 전체 높이와 일치시켰다.
- 국가별 미술 연표에서 휠 위·아래는 시간축 확대·축소, 왼쪽 버튼 드래그는 가로·세로 화면 이동으로 동작하도록 추가했다.

- 휠 확대·축소를 시간축 전용이 아닌 카드·사조 행·시간축 전체에 같은 가로세로 비율로 적용하도록 변경했다.

- 사조 행·막대 높이를 카드 최대 높이뿐 아니라 설명, 목록 여백, 막대 테두리까지 포함해 자동 산정하도록 보정해 카드 전체가 잘리지 않게 했다.

- 국가별 미술 오른쪽 화면에서 기간 슬라이더와 표시 밀도 슬라이더를 제거하고, 확대·축소는 연표 위 휠 조작으로만 제공하도록 정리했다.

- 국가별 미술 오른쪽 연표 패널의 하단 여백을 제거하고 연표 스크롤 영역이 상단 탭 영역 아래부터 화면 바닥까지 남은 높이를 모두 사용하도록 확장했다.

- 국가 변경 시 모든 사조 행이 화면에 들어오는 기본 배율을 자동 계산하고, 연표 더블클릭 또는 마우스 휠 버튼 두 번 클릭으로 기본 배율을 복원하도록 했다.
- 국가별 미술 탭의 오른쪽 위 탭 모음에 관리자용 전체 규칙 점검 버튼을 추가하고, 왼쪽 사조·연도 표기를 가운데 정렬 및 반응형 가독성 크기로 조정했다.

- 왼쪽 사조명과 기간 글자를 기존 기준의 2배 크기로 조정하고 화면 폭에 따라 자동 보정하도록 했다.
- 기본 배율 복원을 더블클릭·휠 버튼 동작에서 연표 오른쪽 클릭의 기본 비율로 보기 메뉴 선택 방식으로 변경했다.

- 사조명·기간 글자에 역배율을 적용해 연표 확대·축소와 무관하게 현재 실제 크기로 유지하고, 가장 긴 사조명·기간을 측정해 사조 컬럼 폭을 한 줄 표시 가능한 크기로 자동 계산하도록 변경했다.

- 직전의 배율 무관 글자 고정과 이름 길이 기반 사조 컬럼 폭 자동 확장 변경을 취소하고, 가운데 정렬·2배 글자 크기 상태로 되돌렸다.

- 사조 컬럼 폭을 한글 약 두 글자만큼 넓히고, 이미지 카드가 있는 사조 막대를 더블클릭하면 3배 크기의 비모달 미리보기와 닫기 아이콘을 표시하도록 추가했다.

- 사조 막대의 더블클릭이 드래그 처리에 의해 취소되던 문제를 수정해, 이미지 카드가 있는 막대의 확대 미리보기가 정상적으로 열리도록 했다.

- 사조 막대 확대 미리보기를 현재 표시 막대의 2배 크기로 조정하고, 포함된 모든 이미지 카드가 내부 폭에 맞춰 한 번에 보이도록 카드 격자를 재배치했다.

- 사조 막대 확대 미리보기가 원본 막대의 실제 카드·글자 비율을 유지하도록 변경했다. 원본의 전체 카드 폭과 높이를 기준으로 2배 확대하며, 화면 한계를 넘는 경우에도 전체 카드를 보이게 가능한 범위 안에서 함께 축소한다.

- 사조 막대 확대 미리보기를 기존보다 20% 키우고, 미리보기 속 작품 이미지에 마우스를 올리면 해당 이미지를 2배로 보여 주는 최상위 돋보기 미리보기를 추가했다.

- 확대 미리보기의 작품 돋보기 배율을 4배로 높이고, 확대 막대의 좌우·상하 바깥 여유 공간 중 가장 넓은 위치에 표시해 다른 작품 이미지를 가리지 않도록 했다.

- 작품 돋보기에 이미지뿐 아니라 카드의 제목·연도 설명까지 함께 복제해 원본 카드와 동일한 비율로 확대되도록 보완했다.

- 국가를 바꿀 때 이전 국가에서 열어 둔 사조 확대 미리보기와 작품 돋보기가 자동으로 닫히도록 했다.

- 작품 돋보기 안의 카드 설명 및 연도 글자 크기를 기존의 절반으로 조정하고 이미지 확대 비율은 유지했다.

- 작품 돋보기를 왼쪽 사이드바보다 해당 카드 가까이에 열도록 배치 우선순위를 오른쪽·아래·위·왼쪽으로 조정하고, 선택한 카드 중심에 맞춰 위치시켰다.

- 국가 판정이 영어 국가명의 부분 문자열을 오인하지 않도록 보완했다. 이에 따라 프로이센(Prussia) 화가인 프리드리히가 러시아(Russia) 낭만주의 카드로 잘못 들어가던 문제를 수정했다.

## UI 정리

- 화가·사조·기법·용어·주제-사건 탭 이동을 이름 있는 탭 재사용 방식으로 통일하고, 이미 열린 탭은 재로딩 없이 포커스하도록 조정
- 화가 목록 상단 로고·탭 제목·로그아웃 위치와 형식을 통일하고 Firebase 내보내기 버튼은 화면에서 제거하되 서버 마이그레이션 API는 보존
- 화가 목록 행을 압축하고 생몰연 글자와 국가 원형 아이콘 폭을 정리해 한 화면에 더 많은 화가가 보이도록 조정
- 기법·용어 설명 화면의 제목단과 정의 설명 사이 여백을 크게 줄여 설명 문단 노출량을 확대

## 사조 탭 레이아웃

- 미술 사조의 이해 탭에 로고·제목·하단 로그아웃만 남기는 전용 왼쪽 사이드바를 적용하고, 기존 화가 검색·목록 제어는 사조 탭에서 숨겼다.
- 사조 탭의 중복 본문 로고·제목과 별도 로그아웃 버튼을 제거하고, 탭 이동 버튼은 오른쪽 위 고정 영역에 유지했다.
- 역사 사건 열은 라벨 실제 표시 폭에 따라 180~360px 범위에서 자동 조절되도록 했다. 사조 막대 더블클릭 새 탭 열기와 관리자 우클릭은 유지했다.

- 사조 탭 오른쪽 본문 상단 여백을 76px로 확보해, 고정된 탭 이동 버튼과 사조 콘텐츠 상단이 겹치지 않게 했다.

- 역사 사건 보기·숨기기와 역사 사건 추가 버튼을 사조 전용 사이드바의 제목 바로 아래로 옮기고, 본문 상단의 고정 버튼 영역은 제거했다.

- 국가 선택을 역사 사건 버튼 아래 사조 사이드바로 옮기고, 접기 메뉴 대신 전체 국가 체크박스를 두 열로 항상 표시하도록 바꿨다.

- 사조 막대와 레인 간격을 10% 줄여 가로 폭을 100px에서 90px로 조정하고, 기간 선택 영역의 최대·상대 폭을 20% 늘렸다.

- 사조 비교 막대 위 국가명을 각 국가 컬럼 가운데로 정렬했다.

## 사조 탭 역사 사건 분류

- 역사 사건 표시를 사회·정치·역사, 종교·사상, 미술사 중 하나만 선택해 보도록 바꾸고 다른 분류 사건은 숨기도록 했다.
- 종교개혁과 트리엔트 공의회 등 종교 사건은 미술 영향과 관계없이 종교·사상으로 분류했으며, 사건 라벨 클릭의 위키피디아 새 탭 열기 동작은 유지했다.
- 관리자가 새 역사 사건을 추가할 때 분류를 선택하도록 하고, 기존 사용자 추가 사건은 사회·정치·역사로 안전하게 처리한다.

- 역사 사건 라벨을 클릭하면 위키피디아 검색 결과를 별도 팝업이 아닌 새 브라우저 탭으로 열도록 변경했다.

- 사건 분류 버튼을 가로 한 줄의 3등분 배열로 바꾸고, 사회·정치·역사 표기를 사회·정치로 줄였다.

## 사조 비교 국가 확장

- 사조 비교에 벨기에·오스트리아·노르웨이를 추가하고, 각 국가의 핵심 미술 흐름과 기간을 등록했다.
- 기존에 전체 국가를 선택해 사용하던 화면에는 새 3개 국가를 자동으로 포함하되, 개별 국가 선택 상태는 그대로 보존한다.

## 국가별 미술 탭

- 국가별 미술 전용 탭을 추가해 한 국가만 선택하고 1400~1950년 사조 변천을 넓은 단일 연표로 표시하도록 했다.
- 이 탭은 사조 설명 HTML의 기존 대표작 카드와 이미지 경로를 직접 재사용하며, 편집·추가·삭제와 이미지 복사는 하지 않는다. 자료가 없으면 대표작 자료 없음으로 표시한다.
- 화가·사조·기법·주제 탭의 공통 이동 영역에도 국가별 미술 탭을 같은 이름 있는 탭 재사용 규칙으로 연결했다.
- README에 국가별 미술 탭의 범위, 읽기 전용 대표작 표시 원칙, 보강 위치를 문서화했다.

## 국가별 미술 및 사조 설명

- 국가별 미술의 사조 막대 카드가 사조 설명 문서 마지막 심화 대표작 카드의 문서 순서를 그대로 따르도록 연도 재정렬을 제거했다.
- 관리자용 사조 설명 심화 카드에 같은 카드 그리드 안에서만 가능한 드래그 정렬과 저장을 추가했으며, 저장 뒤 국가별 미술 카드 캐시도 갱신하도록 했다.

- 사조 심화 카드 순서를 저장하면 localStorage 갱신 신호로 열려 있는 국가별 미술 탭의 문서 캐시와 확대 미리보기를 자동 갱신해 새 순서를 즉시 반영하도록 했다.
- 심화 대표작 카드를 국가·지역 세부 전개별 독립 그리드로 분리하고, 드래그 이동을 해당 그리드 안으로 제한하도록 보완했다.

## 이미지 및 문서 정리

- 다운로드 폴더 기준을 프로젝트 루트 다운로드용 폴더만 확인하는 표현으로 README에 통일
- 10MB를 넘던 리고 루이 14세 이미지를 PNG로 변환하고 기존 JPG 참조를 PNG로 갱신

## 국가별 미술 사건

- 국가별 미술 탭에 각국 사건 레일을 추가하고 확대 단계에 따라 점·핵심 라벨·전체 라벨로 표시
- 15개 국가의 미술 전환 관련 사건 97개를 data/country-art-events.json에 독립 저장
- 국가별 사건 클릭 시 연결된 위키피디아 문서를 새 탭으로 여는 동작 추가

- 각 나라별 사건 데이터를 보강해 국가별 미술 사건 수를 97개에서 160개로 확대
- 후원, 전쟁, 제도, 기술, 종교 사건을 추가해 사조 전환 맥락을 더 촘촘하게 표시

## 국가별 사조 배경

- 국가별 사조 발생 배경 데이터 파일을 추가하고 15개국 73개 핵심 사조 설명을 연결
- 국가별 미술 막대에 배경 보기 버튼과 연결 사건 패널을 추가
- 배경 설명은 data/country-movement-backgrounds.json에, 사건은 data/country-art-events.json에 독립 저장하도록 유지

- 사조 배경 버튼을 막대 오른쪽 끝에서 시작점 쪽 왼쪽 위로 이동
- 배경 버튼 표기를 i에서 원형 느낌표로 바꿔 사조 시작 배경 안내 의미를 명확화

- 사조 배경 패널의 사건을 사조 시작 연도 기준으로 태동 전 조건과 공식화·확산 사건으로 분리
- 73개 국가별 사조 배경 모두 시작 이전 전사건을 최소 1개 이상 갖도록 preludeEventIds와 국가 사건 데이터를 보강
- 독일 제국자유도시 인문주의, 영국 캑스턴 인쇄술, 스페인 가톨릭 군주 공동통치 사건을 추가

- 사조 배경 느낌표 버튼 크기를 18px에서 27px로 1.5배 확대
