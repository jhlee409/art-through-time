# 변경사항 2026-08-26

## UI 정리

- 화가·사조·기법·용어·주제-사건 탭 이동을 이름 있는 탭 재사용 방식으로 통일하고, 이미 열린 탭은 재로딩 없이 포커스하도록 조정
- 화가 목록 상단 로고·탭 제목·로그아웃 위치와 형식을 통일하고 Firebase 내보내기 버튼은 화면에서 제거하되 서버 마이그레이션 API는 보존
- 화가 목록 행을 압축하고 생몰연 글자와 국가 원형 아이콘 폭을 정리해 한 화면에 더 많은 화가가 보이도록 조정
- 기법·용어 설명 화면의 제목단과 정의 설명 사이 여백을 크게 줄여 설명 문단 노출량을 확대
- 주제-사건 화면의 그림 추가·모자이크 보기 버튼을 제목단에서 이미지 갤러리 박스 안 오른쪽 위로 이동

## 표기와 정렬

- 화가 이름 표기를 한국어 통용명, uHangul 성·이름 순, 국제 원어 표기로 분리하고 사조 설명 문서와 기법·용어에도 같은 기준을 적용
- 화가 목록 정렬을 실제 왼쪽 목록에 보이는 한국어 통용명 기준으로 삼고 이름오름차순·이름내림차순·생년순으로 정리

## 문서

## 안정성 보완

- 주제-사건 데이터에 읽기 전용 /api/topics API를 추가해 화가·기법 API와 제공 방식을 통일
- 일반적인 정적 파일 404(예: favicon, 선택 이미지 인덱스)를 서버 오류 스택으로 기록하지 않도록 조정해 실제 장애 로그 식별성을 개선
