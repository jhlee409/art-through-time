## 국가별 미술 화면

- 국가별 미술 기본 배율이 세로 행 수에 맞춰 축소되더라도 시간축 기준 폭을 현재 배율에 맞춰 자동 확장해, 카드 비율을 바꾸지 않고 오른쪽 가로 공간을 사용하도록 했다.

- 국가별 미술의 기본 시간축 폭을 기본 배율에 고정해 선택 기간 전체가 모니터 오른쪽 경계 안에 맞도록 수정했다. 사용자가 휠로 확대한 경우에만 가로 스크롤이 생긴다.

## 사조 설명 카드·국가 표 동기화

- 사조 설명 문서의 마지막 심화 대표작 카드 순서를 기준으로 국가별 전개 표 각 행의 화가 링크를 자동 재배열하도록 서버 저장·업로드·새로고침 단계에 적용했다.
- 기존 문서도 화면 제공 단계에서 같은 정렬을 적용해 즉시 카드 순서와 표 순서를 일치시키며, 기존 HTML을 일괄 덮어쓰지 않고 다음 저장 시에만 반영한다.
- 사조 HTML 작성 규칙에 카드 순서 변경 시 국가별 전개 표 화가 링크가 자동 동기화되는 표준을 추가했다.

- 중첩된 국가별 심화 카드 그룹까지 순서를 읽도록 보완해, 바로크 네덜란드 황금기처럼 렘브란트·페르메이르·할스 카드 순서가 대표 화가 표 셀에 그대로 반영되게 했다.

## 화가 관계도

- 작품 연표 제목의 화가 이름을 클릭하면 새 화가 관계도 탭을 열도록 추가했다.
- 관계도는 중앙 화가를 기준으로 선행 학습 화가·스승·교류 화가·경쟁 화가를 좌·상·우·하에 배치하고, 교류는 하늘색·경쟁은 적색 타원으로 표시한다.
- 검증된 관계를 data/artist-relations.json의 화가 ID별 study, teachers, exchanges, rivals 배열에서 읽도록 했으며, 확인되지 않은 관계는 표시하지 않는다.

- 관계도 끝 노드의 글자 크기를 13px에서 26px으로 두 배 확대했다.
- 마사초 관계도에 영문 위키피디아 근거로 조토의 작품 연구와 마솔리노·브루넬레스키·도나텔로의 공동작업·교류를 등록했다. 문서에 교육·경쟁 근거가 없는 항목은 비워 두었다.

- 중앙 화가명과 모든 관계 타원 이름을 26px로 통일하고 가운데 정렬했다.
- 관계 타원은 줄바꿈 없이 한 줄 가로 배열로 유지하며, 공간이 부족하면 해당 방향에서 가로로 이동해 볼 수 있게 했다.

- 관계도 전용 탭에서 왼쪽 사이드바를 숨겨 관계도 영역이 화면 전체 가로 폭을 사용하도록 했다.
- 관계 연결선을 45도(우상), 135도(좌상), 225도(좌하), 270도(하) 방향으로 바꾸고 각 관계군을 해당 방향에 배치했다.

- 왼쪽 사이드바를 복구하고 관계도 캔버스는 오른쪽 패널의 좌우 여백 없이 전체 폭을 사용하도록 조정했다.
- 교류 화가 등 관계 타원은 스크롤 없이 가용 폭에서 한 줄로 표시하도록 했고, 관계 화가 글자는 26px의 약 70%인 18px로 줄였다.
- 연결선은 굵기 3px, 길이 144px로 각각 세 배·두 배 확대했으며 대립·경쟁 방향은 315도(우하)로 변경했다.

- 각 관계군을 중심 타원에서 뻗은 직선의 끝점 바로 옆에 배치해 첫 관계 타원이 선 끝에서 시작하도록 정렬했다.
- 좌측 방향 관계군은 선 끝에 첫 화가가 오도록 가로 순서를 반전했고, 연구·모사 화가는 좌상(135도), 스승은 좌하(225도) 위치로 서로 교체했다.

- 관계도를 절제된 관계 지도 스타일로 재설계했다. 은은한 점 배경, 얇은 구획선, 관계 유형 배지, 정돈된 타원과 단계별 그림자를 적용해 중심 화가·관계 유형·연결 화가의 위계를 분명히 했다.
- 교류·경쟁 관계의 색상은 채도를 낮춘 하늘색·적색으로 조정하고, 연결선과 중심 노드의 대비를 유지해 가독성을 높였다.

- 각 관계군을 독립된 둥근 테두리 박스로 묶어 연결선·관계 유형·화가 목록의 소속을 한눈에 구분할 수 있게 했다.
- 교류·경쟁 관계 박스에는 각 관계의 하늘색·적색 계열 테두리와 옅은 배경을 적용했다.

- 중앙 화가만 타원 노드로 유지하고, 관계 화가 이름은 관계군 박스 안의 간결한 텍스트 링크로 변경했다.
- 좌측 관계군의 화가 이름은 박스 오른쪽 안쪽에서, 우측 관계군은 박스 왼쪽 안쪽에서 시작하도록 정렬했다. 각 연결선 끝은 위쪽 박스의 아래 중심 모서리 또는 아래쪽 박스의 위 중심 모서리에 맞췄다.

- 관계 화가 이름을 쉼표로 구분한 링크 목록으로 바꿨다. 화가 목록 등록 인물은 내부 연표 링크, 외부 인물은 위키피디아 링크, 링크가 없는 인물은 agentAnswer 안내 패널을 표시한다.
