# 변경사항 2026-08-27

이 문서는 일별 작업 이력이 아니라 이후 작업에서 계속 참고할 운영 기준만 보관한다. 상세 이력은 Git 변경 기록과 각 작성규칙 문서를 따른다.

## 공통 화면·인증

- 새 탭은 `작성규칙/공통_탭구조.md`의 사이드바 이름 표기 아이콘, 우측 상단 탭·전체 규칙 점검 버튼, 주 화면 폭, 인증 상태 기준을 모두 적용한다.
- 어느 탭에서 로그아웃하든 열린 프로젝트 탭의 세션을 함께 정리하고 로그인 화면으로 전환한다.
- 새 프로젝트 탭도 유효한 관리자 세션을 이어받아 편집 아이콘과 관리자 도구를 일관되게 표시하며, 세션 만료·로그아웃 시에는 공유 세션을 제거한다.
- 로그인 후 주소에 특정 화가·전용 탭 요청이 없으면 기본 첫 화면은 `미술 사조의 이해`다.

## 화가 및 작품

- 작품 연표에서 선택한 화가는 왼쪽 목록 스크롤 영역의 세로 중앙에 표시한다. 이때 선택 항목과 오른쪽 연표의 위치는 바꾸지 않는다.
- 사용자 제공 로컬 작품 파일은 요청 범위에서 모두 점검·등록한다. 같은 작품의 새 파일은 중복 작품 대신 기존 이미지 연결을 교체하고, 대표작 변경은 연표·사조 카드·설명을 함께 맞춘다.


- 화가 탭의 오른쪽 작품 화면이 본문 가로 공간을 전부 쓰도록 좌우 여백을 줄이고 작품 그리드 칸을 가변 폭으로 변경했다.

## 사조 설명 문서

- 공통 레이아웃·국가 카드 문맥·상단 고정 사조명 규칙은 `작성규칙/사조html_작성규칙.md`를 따른다.
- 공통 사조 HTML 규칙을 바꾸면 `node tools/sync-all-movement-html-rules.js`로 모든 저장본에 동기화하고 검증한다.
- 심화 대표작 카드의 순서는 국가별 전개 표의 대표 화가 나열 순서와 동기화한다.
- 카드 대표작은 해당 국가·세부 사조의 특징을 가장 잘 설명하는 작품으로 고르며, 교체할 때 이미지·대체 텍스트·고해상도 경로·작품명·연도·지역·설명을 함께 갱신한다.

## 화가 관계도와 영향 사건

- 관계도에는 미술가만 표시한다. 군주·후원자·정치인 등 비미술가는 `impactEvents`의 영향 사건으로 기록한다.
- 협업은 실제 공동 제작·화실·프로젝트 관계가 확인된 미술가만 기록하며, 영향·후원·경쟁을 서로 혼동하지 않는다.
- 영향 사건은 출생 배경, 교육·이동·후원·제도 변화 및 생존 중 직접 영향을 확인할 수 있는 전쟁·혁명·침략·점령·역병 등을 출처와 함께 기록한다.
- 화가 작품 이미지를 새로 추가하면 관계도·영향 사건 자동 감사를 실행하고, 역사 사건은 출처를 재검토한다. 기준과 수동 실행 방법은 `작성규칙/화가관계도탭_작성규칙.md`를 따른다.

## 이미지·데이터 운영

- 외부 이미지 URL은 새로 의존하지 않는다. 사용자 제공 로컬 파일은 프로젝트 로컬 경로로 등록하고, 이미지가 없는 항목은 업로드 예정 상태로 둔다.
- 작품의 제작 시기는 숫자 `year`와 선택적 `yearEnd`로 저장한다. 화면의 생몰년 필터와 연표 정렬을 위해 ‘1750–1752년경’ 같은 문자열을 `year`에 넣지 않는다.
- JFIF 로컬 파일은 JPEG MIME 형식으로 제공한다.
- Firebase 내보내기는 향후 데이터베이스 이관용으로 보존하며, 일상 편집에서는 실행하지 않는다. 이관 전 검증 절차는 `FIREBASE_MIGRATION.md`를 따른다.
- 외부 이미지 다운로드는 대상 사이트·파일을 밝힌 뒤 사용자의 명시적 승인을 받아야 한다. 이미 `다운로드용/`에 있는 로컬 파일은 외부 다운로드보다 우선한다.
- 새 기법·용어는 공통 분류 필터 태그를 포함해 현재 필터·검색에서 보이는지 확인하고, 대표작 이미지는 확인된 로컬 자산만 사용한다.

- 현재 프로젝트 점검 기준은 100개 검사 통과 상태다.

## 실행과 운영

- Art_through_Time.cmd에서 서버가 10초 안에 응답하지 않을 때 브라우저를 열지 않고 최근 오류 로그를 표시하도록 보강했다.
- README에 서버 시작 실패 동작과 로컬 이미지 Junction 백업 주의를 명시했다.

- Art_through_Time.cmd가 새 서버를 띄울 때 서버용 CLI 창을 보이게 남기지 않고 숨김으로 실행하도록 바꿨다.

## 국가별 미술

- 국가별 사건 레일에서 미술사 영향 전쟁을 eventKind war로 구분하고, 전쟁 이름을 기간선 왼쪽에 표시하도록 했다.
- 전쟁 기간선은 해당 국가 기준 승전 붉은색, 패전 초록색, 불명확 검은색 굵은 실선으로 표시한다.
- 국가별 사건 검증에 eventKind와 countryOutcome 허용값 검사를 추가했다.

- 국가별 미술 탭의 사건 레일 높이를 216px로 늘리고 사건·범례 글자 크기를 기존 대비 1.5배로 키웠다.

- 국가별 미술 탭의 모든 사건 라벨을 시작점 왼쪽에 표시하도록 통일했다.
- 맨 위 연도칸 높이를 76px로, 연도 글자를 20px로 키워 기존 대비 두 배 기준에 맞췄다.

- 국가별 미술 막대 표를 확대하거나 가로 이동해도 국가명·사조·사건·사조명 열이 화면 왼쪽에 고정되도록 했다.

- 국가별 미술 기본 배율에서는 고정용 복제 사조 열을 숨기고, 확대 후 가로 이동할 때만 표시되도록 중복 표시를 수정했다.

- 국가별 미술 확대·축소·드래그 중 고정 사조 열이 움직이지 않도록 X축 이동 보정을 제거하고 스크롤 영역 왼쪽 경계에 붙게 했다.

- 국가별 미술의 왼쪽 국가 선택 사이드바와 막대 표 사조명 라벨 열 폭을 각각 10% 줄여 오른쪽 막대 영역을 넓혔다.

## 연표 표시

- 화가 시기별 연표와 국가별 미술 시간축의 연도 표기를 세기 단위로 간략화해 통일했다.
- 세기 라벨은 해당 영역 가운데 정렬하고, 경계선과 하나 건너 옅은 복숭아색 배경으로 구분하도록 했다.

- 화가 및 작품의 일반 세로 작품 연표와 미술 사조의 이해 세로축도 세기 단위 박스·수평 경계선·교차 복숭아색 배경 방식으로 통일했다.

## 탭 라우팅

- 루트 기본 화면을 미술 사조의 이해 레이아웃으로 맞추고, 화가 탭은 artists 파라미터로 분리했으며, 이미 열린 탭도 URL이 다르면 요청 탭으로 다시 이동하게 했다.

- countryArt·movementPopup·artist 파라미터가 함께 남은 오래된 탭에서도 전용 탭 우선순위가 깨지지 않도록 화면 모드 판정을 보강했다.
