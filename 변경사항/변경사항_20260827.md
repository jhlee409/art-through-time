# 변경사항 2026-08-27

이 문서는 일별 작업 이력이 아니라 이후 작업에서 계속 참고할 운영 기준만 보관한다. 상세 이력은 Git 변경 기록과 각 작성규칙 문서를 따른다.


- 사조별 대표작과 양식적 전환이 이루어진 제작 국가를 movementActivityCountry로 우선 매칭하도록 하고, 반 고흐를 프랑스 후기 인상주의 행에 표시하며 네덜란드 국적·기존 활동 지역은 보존

- 반 고흐의 확인된 활동 지역을 네덜란드·프랑스로 시간순 보완하고, 화가 리스트의 프랑스 후기 인상주의 행 매칭을 데이터와 작성 기준에 일치시킴

- 오른쪽 사조 막대의 모든 화가 이름 상자를 전체 화면에서 가장 낮은 상자 높이와 글꼴 크기로 통일하고, 행별 높이 확대·축소와 개별 높이 보정을 제거

## 공통 화면·인증

- 새 탭은 `작성규칙/공통_탭구조.md`의 사이드바 이름 표기 아이콘, 우측 상단 탭·전체 규칙 점검 버튼, 주 화면 폭, 인증 상태 기준을 모두 적용한다.
- 어느 탭에서 로그아웃하든 열린 프로젝트 탭의 세션을 함께 정리하고 로그인 화면으로 전환한다.
- 새 프로젝트 탭도 유효한 관리자 세션을 이어받아 편집 아이콘과 관리자 도구를 일관되게 표시하며, 세션 만료·로그아웃 시에는 공유 세션을 제거한다.
- 로그인 후 주소에 특정 화가·전용 탭 요청이 없으면 기본 첫 화면은 `미술 사조의 이해`다.

## 화가 및 작품

- 작품 연표에서 선택한 화가는 왼쪽 목록 스크롤 영역의 세로 중앙에 표시한다. 이때 선택 항목과 오른쪽 연표의 위치는 바꾸지 않는다.
- 사용자 제공 로컬 작품 파일은 요청 범위에서 모두 점검·등록한다. 같은 작품의 새 파일은 중복 작품 대신 기존 이미지 연결을 교체하고, 대표작 변경은 연표·사조 카드·설명을 함께 맞춘다.


- 화가 탭의 오른쪽 작품 화면이 본문 가로 공간을 전부 쓰도록 좌우 여백을 줄이고 작품 그리드 칸을 가변 폭으로 변경했다.

## 사조 설명 문서

- 공통 레이아웃·국가 카드 문맥·상단 고정 사조명 규칙은 `작성규칙/사조html_작성규칙.md`를 따른다.
- 공통 사조 HTML 규칙을 바꾸면 `node tools/sync-all-movement-html-rules.js`로 모든 저장본에 동기화하고 검증한다.
- 심화 대표작 카드의 순서는 국가별 전개 표의 대표 화가 나열 순서와 동기화한다.
- 카드 대표작은 해당 국가·세부 사조의 특징을 가장 잘 설명하는 작품으로 고르며, 교체할 때 이미지·대체 텍스트·고해상도 경로·작품명·연도·지역·설명을 함께 갱신한다.

## 화가 관계도와 영향 사건

- 관계도에는 미술가만 표시한다. 군주·후원자·정치인 등 비미술가는 `impactEvents`의 영향 사건으로 기록한다.
- 협업은 실제 공동 제작·화실·프로젝트 관계가 확인된 미술가만 기록하며, 영향·후원·경쟁을 서로 혼동하지 않는다.
- 영향 사건은 출생 배경, 교육·이동·후원·제도 변화 및 생존 중 직접 영향을 확인할 수 있는 전쟁·혁명·침략·점령·역병 등을 출처와 함께 기록한다.
- 화가 작품 이미지를 새로 추가하면 관계도·영향 사건 자동 감사를 실행하고, 역사 사건은 출처를 재검토한다. 기준과 수동 실행 방법은 `작성규칙/화가관계도탭_작성규칙.md`를 따른다.

## 이미지·데이터 운영

- 외부 이미지 URL은 새로 의존하지 않는다. 사용자 제공 로컬 파일은 프로젝트 로컬 경로로 등록하고, 이미지가 없는 항목은 업로드 예정 상태로 둔다.
- 작품의 제작 시기는 숫자 `year`와 선택적 `yearEnd`로 저장한다. 화면의 생몰년 필터와 연표 정렬을 위해 ‘1750–1752년경’ 같은 문자열을 `year`에 넣지 않는다.
- JFIF 로컬 파일은 JPEG MIME 형식으로 제공한다.
- Firebase 내보내기는 향후 데이터베이스 이관용으로 보존하며, 일상 편집에서는 실행하지 않는다. 이관 전 검증 절차는 `FIREBASE_MIGRATION.md`를 따른다.
- 외부 이미지 다운로드는 대상 사이트·파일을 밝힌 뒤 사용자의 명시적 승인을 받아야 한다. 이미 `다운로드용/`에 있는 로컬 파일은 외부 다운로드보다 우선한다.
- 새 기법·용어는 공통 분류 필터 태그를 포함해 현재 필터·검색에서 보이는지 확인하고, 대표작 이미지는 확인된 로컬 자산만 사용한다.

## 국가별 미술

- 국가별 사건 레일에서 미술사 영향 전쟁을 eventKind war로 구분하고, 전쟁 이름을 기간선 왼쪽에 표시하도록 했다.
- 전쟁 기간선은 해당 국가 기준 승전 붉은색, 패전 초록색, 불명확 검은색 굵은 실선으로 표시한다.
- 국가별 사건 검증에 eventKind와 countryOutcome 허용값 검사를 추가했다.

- 국가별 미술 탭의 사건 레일 높이를 216px로 늘리고 사건·범례 글자 크기를 기존 대비 1.5배로 키웠다.

- 국가별 미술 탭의 모든 사건 라벨을 시작점 왼쪽에 표시하도록 통일했다.

- 국가별 미술 막대 표를 확대하거나 가로 이동해도 국가명·사조·사건·사조명 열이 화면 왼쪽에 고정되도록 했다.

- 국가별 미술 기본 배율에서는 고정용 복제 사조 열을 숨기고, 확대 후 가로 이동할 때만 표시되도록 중복 표시를 수정했다.

- 국가별 미술 확대·축소·드래그 중 고정 사조 열이 움직이지 않도록 X축 이동 보정을 제거하고 스크롤 영역 왼쪽 경계에 붙게 했다.

- 국가별 미술의 왼쪽 국가 선택 사이드바와 막대 표 사조명 라벨 열 폭을 각각 10% 줄여 오른쪽 막대 영역을 넓혔다.

- 확대 시 화가 이름 글자가 세로 확대량을 따라 실제로 커지도록 가로·세로 보정 배율을 분리해 적용했다.

- 화가 이름 글자의 최종 확대 배율과 높이가 가로 확대 배율을 따르도록 보정하고, 사조명 행 드래그로 현재 화면의 사조 순서를 임시 변경할 수 있게 했다.

- 화가 이름 박스의 글자 크기를 기본 전체보기 배율로 보정해, 화면상 이름 크기가 현재 가로 확대 배율에 맞춰 실제로 커지도록 수정했다.

- 화가 이름 확대가 말줄임 폭에 막히지 않도록 이름 내부 폭을 기본 배율에 맞춰 보정하고, 최종 글자 크기가 가로 확대 배율을 따르도록 다시 정리했다.

- 비균등 확대 레이어 안의 화가 이름 역보정 변환을 제거하고, 막대의 실제 화면 위치를 기준으로 별도 오버레이 이름 상자를 그리도록 바꿨다. 이름 상자와 글자 크기는 가로 확대 비율을 직접 따라 확대·축소된다.

- 화가 생애 이름 상자의 확대량을 기본 비율 이후 두 배로 강화하고, 같은 사조 행 안의 상자 위치·높이·글꼴 크기에 공통 배율을 적용해 확대 시 상자 간 세로 간격이 과도하게 벌어지지 않도록 조정했다. 글자는 가로·세로 1:1 비율을 유지한다.

- 화가 생애 이름 상자의 가로 생애 길이는 유지하고, 현재 목록 전체에서 가장 작은 이름 상자 높이와 글꼴 크기를 공통값으로 적용했다. 공통 높이에 맞춰 사조 행 안의 패킹 줄도 다시 계산한다.

- 화가 생애 이름 상자와 글꼴의 확대 강화 계수를 2에서 2.4로 높여, 기본 비율 이후 확대량이 직전보다 20% 더 커지도록 조정했다.

- 화가 생애 이름 상자와 글꼴의 확대 강화 계수를 2.4에서 2.88로 높여, 직전 확대 배율보다 1.2배 더 커지도록 조정했다.

- 화가 생애 이름 상자와 글꼴의 확대 강화 계수를 2.88에서 3.2로 조정했다.

- 화가 생애 이름 상자와 글꼴의 확대 강화 계수를 3.2에서 3.6으로 조정했다.

- 화가 리스트의 기본 연표 배율을 화면 맞춤값의 1.4배로 올리고, 기본 화면에서도 가로·세로 스크롤바를 표시해 전체 연표 이동을 허용했다. 국가별 미술 탭의 기본 배율에는 영향을 주지 않는다.

- 오른쪽 연표의 세기 박스와 고정 세기 축 높이를 76px에서 38px로 줄이고, 세기 라벨 글자를 20px에서 14px(70%)로 축소했다. 국가별 미술 탭의 시간축 크기는 유지한다.

- 오른쪽 상단의 선택 국가 셀과 사조 셀을 사조(선택 국가 n개) 단일 헤더로 통합하고, 실제 높이가 세기 박스와 같은 38px가 되도록 고정·확대 레이어에 함께 적용했다.

- 화가 리스트 기본 연표 배율을 1.4에서 1.68로 높여, 직전 기본 화면보다 1.2배 크게 표시되도록 조정했다.

- 화가 리스트 기본 화면에서 세로 확대 1.68은 유지하되, 시간축 가로 폭을 기본 배율에 맞춰 축소하고 세로 스크롤바 여유를 남겨 모든 막대가 가로 화면 안에 들어오게 했다. 기본 가로 스크롤은 숨기고 추가 휠 확대 때만 가로 이동을 허용한다.

- 화가 생애 이름 막대의 공통 세로 높이를 기존 최소 상자 높이의 1.2배로 높이고, 변경된 높이를 사조 안의 패킹 계산에도 반영했다. 글꼴 크기와 생애 가로 길이는 유지한다.

- 화가 리스트의 최대 가로 확대 한계를 1.5에서 2.25로 높여, 기존 최대 확대 배율의 1.5배까지 확대할 수 있게 했다.

- 화가 생애 이름 상자의 높이 확대 계수를 글자 공통 계수 3.6의 1.4배인 5.04로 분리해, 확대 시 상자 높이가 기존보다 1.4배 더 크게 커지도록 조정했다. 글꼴 확대율은 유지한다.

- 화가 생애 이름 상자의 세로 위치를 막대 전체의 비균등 세로 확대에서 분리하고, 기본 화면의 행 안쪽 위치를 기준으로 상자 높이와 같은 확대 배율을 적용했다. 같은 사조 행 안의 이름 상자 간격 비율이 확대 전후 유지된다.

- 각 사조 행의 마지막 이름 상자 하단과 사조 상자 하단 사이의 기본 여백을 계산해, 확대 시 이름 상자 높이 배율과 같은 비율로 유지하도록 이름 상자 묶음의 세로 위치를 보정했다.

- 화가 생애 이름 상자의 가로 폭은 기본 화면 길이로 고정하고, 각 상자의 높이·행 안쪽 위치·상자 간격·하단 여백을 사조 행의 실제 세로 확대율과 동일하게 계산하도록 통합했다.

- 모든 화가 생애 이름 상자의 테두리를 검은색 1px 실선으로 통일하고, 사조 기간을 넘는 예외 상자의 별도 테두리 스타일을 제거했다.

- 화가 생애 이름 상자의 가로 폭 고정을 제거하고, 확대된 시간축의 실제 화면 폭을 사용해 왼쪽 출생년과 오른쪽 사망년 좌표를 항상 정확히 따르도록 수정했다.

- 화가 리스트의 고정 세기 축은 확대·축소 시 세로 배율을 적용하지 않도록 바꾸고, 가로 시간축 배율에 의한 세기 라벨 너비는 역보정해 세기 박스 높이 38px와 글자 크기 14px를 항상 유지하도록 했다.

- 화가 리스트의 왼쪽 고정 사조 열은 행의 위치·높이는 연표 확대율을 계속 따르되, 사조명·국가·기간·상단 헤더 글자에는 기본 화면 배율 기준의 역보정을 적용해 확대·축소해도 글자 크기가 변하지 않도록 했다.

- 화가 리스트 기본 화면의 화가 생애 이름 상자 공통 높이 계수를 1.2에서 1.44로 올려, 현재보다 1.2배 높은 상자로 표시되도록 조정했다. 확대 상태에서도 같은 높이 비율을 유지한다.

- 화가 리스트의 국가 선택 기준을 화가의 주요 활동 지역( egions 마지막 값) 하나로 바꾸고, 역사 국가명은 기존 현재 국가명 정규화 표를 거쳐 단일 국가에 매칭하도록 정리했다. 사조 매칭은 표시 규칙 외에 사조 계층과 플랑드르 바로크 표기 별칭도 비교하도록 보완했다. 축소 때 음수가 되던 이름 글자 확대 계수는 최소 35%로 제한하고, 이름 상자는 다음 패킹 줄과 행 하단의 사용 가능 높이를 넘지 않게 제한했다. README의 이름 상자 높이 수치도 1.44배로 동기화했다.

- 화가 이름 글자 크기의 별도 가로 확대 강화 계수를 제거하고, 각 이름 상자의 실제 표시 높이를 기본 화면의 해당 상자 높이로 나눈 비율을 글자 크기에 직접 적용하도록 바꿨다. 상자 높이가 패킹 여유 때문에 제한된 경우에도 글자가 같은 실제 비율로 확대·축소된다.
