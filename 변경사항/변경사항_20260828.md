# 변경사항 2026-08-28


- 화가 리스트 탭을 부모 사조 행과 선택 국가별 세부 사조 하위 상자 구조로 전환했다. 화가 생애 상자는 전체 기간을 유지하고, 하늘색 활동 구간만 해당 하위 사조 기간 안에 표시한다.

- 기본 세로 화면에서 부모 사조 행 약 5개가 보이도록 조정해 국가별 세부 사조 상자와 그 내부 화가 이름 상자의 가독성을 높였다.

- 부모 사조와 세부 사조의 동일 높이 제한을 없앴다. 세부 사조는 공통 높이의 화가 이름 상자 패킹 줄 수에 따라, 부모 사조는 세부 사조 배치에 따라 자동으로 높이를 계산하며, 화가가 없는 부모 사조는 이름 상자 3개 높이를 기본값으로 사용한다.

- 화가 이름 상자를 한 줄 고정으로 유지하고 공통 높이를 기존의 80%로 줄였다. 세부 사조 제목은 상자 내부 대신 상단 테두리 왼쪽에 걸치도록 배치했다.

- 화가 이름 상자를 화가 및 작품 탭 왼쪽 목록과 같은 축약 한글 이름으로 고정하고, 시간상 겹치는 세부 사조 상자의 세로 간격을 넓혔다.

- 세부 사조 제목과 사조 열 제목·보조 정보를 화가 이름 상자와 같은 글꼴 계열·굵기·줄높이로 통일했다.

- 기본 화면의 사조 열과 세부 사조 제목에도 비균등 확대 역보정을 적용해 화가 이름과 같은 정상 가로·세로 비율로 표시되게 했다.

- 세부 사조 제목 글자 크기를 8px에서 12px으로 1.5배 키웠다.

- 세부 사조 안의 화가 이름 상자 줄 간격을 1px로 줄이고, 상단 2px·하단 8px의 비대칭 안쪽 여백을 적용했다.

- 세부 사조 상단 경계와 첫 화가 이름 상자 사이 여백을 2px에서 6px으로 늘렸다.

- 세부 사조가 있는 부모 사조의 기간 막대를 숨기고, 같은 부모의 세부 사조 상자에는 공통 바탕색을 적용했다. 부모 사조별 색은 여섯 색 팔레트를 순환한다.

- 부모 사조 막대 조건부 렌더링에서 세부 사조 목록의 변수 범위를 수정해 화면 전체가 표시되지 않던 오류를 복구했다.

- 화가 리스트의 부모·세부 사조 레이아웃, 가변 높이, 공통 이름 상자, 확대 역보정, 드래그 정렬과 공유 탭 분기를 회귀 점검했다. 국가별 미술·사조·화가 및 작품 탭 경로와 로컬 서버의 화면·스크립트·데이터 응답이 정상임을 확인했다.

- 세기별 가로 폭을 기본 맞춤 폭의 1.3배로 늘려 화면 밖 시간 구간을 가로 스크롤·드래그로 탐색하게 하고, 세기·사조 행 경계선을 더 진하게 표시했다.

## 미술사조 이해 탭

- 오른쪽 위 표시 밀도 슬라이더를 제거하고 사조 비교 영역의 마우스 휠로만 세로 확대값을 조절하도록 변경
- 미술 사조의 이해 탭 전용 휠 확대 범위를 0.5x~5x로 설정하고 가로 폭은 유지하도록 반영
- 탭별 휠 줌 방식은 서로 통일하지 않는다는 기준을 README와 미술사조 이해 탭 작성 규칙에 기록

- 사조 비교 영역의 빈 배경을 마우스 왼쪽 버튼으로 드래그하면 상하좌우로 이동하도록 변경
- 사조 탭 드래그 이동이 국가 제목 정렬·사조 막대·역사 사건 버튼과 충돌하지 않도록 예외 처리

- 사조 비교 영역의 휠 세로 확대·축소 감도를 기존 1.1배 계수에서 1.15배 계수로 높임

- 오른쪽 상단 기간 선택 슬라이더 박스를 제거하고 사조 비교 영역을 전체 기간 고정 표시로 변경해 세로 공간을 확보함

- 사건 라벨 겹침을 줄이기 위해 사조 비교 영역의 세로 휠 확대 상한을 5x에서 7.5x로 높임

- 오른쪽 사조 비교 영역이 화면 아래 끝까지 남은 세로 공간을 모두 쓰도록 패널과 기본 차트 높이 계산을 조정함

- 사건 라벨 겹침 완화를 위해 사조 비교 영역의 세로 휠 확대 상한을 7.5x에서 11.25x로 높임

- 역사 사건 분류에 과학·경제를 추가하고 왼쪽 사건 분류 버튼을 한 줄 4개 배치로 변경함

- 가로 드래그 중 사건 컬럼과 세기 표시 컬럼을 왼쪽에 고정하고 두 컬럼의 가로 폭을 기존 대비 80%로 줄임

- 가로 드래그 중 세기 컬럼 왼쪽으로 사조 막대가 비치지 않도록 고정 사건·세기 컬럼 주변에 배경 마스크를 추가함

## 미술 사조의 이해

- 과학·경제 사건에 1629~1631년 이탈리아 페스트, 1665~1666년 런던 대페스트, 1720~1722년 마르세유 대페스트를 추가함

- 기간 사건의 아래 연결선을 사조 탭에서만 4px로 두껍게 하고, 위에서부터 검정·빨강·파랑·초록을 반복 적용함

- 사조 탭의 기간 사건 연결선 시작점을 사건 라벨 중앙에서 왼쪽 끝으로 이동함

- 사건 라벨 수평 연결선을 세기 박스 내부가 아닌 왼쪽 여백까지만 표시하도록 조정함

- 사조 탭의 기간 사건 세로 연결선 시작점을 라벨 왼쪽 테두리에서 사건 이름 첫 글자 아래로 이동함

- 사조 탭의 사건 이름을 줄바꿈 없이 한 줄로 표시하고, 긴 이름에 맞춰 사건 컬럼 폭을 조정함

- 사건 이름 컬럼 폭을 가장 긴 라벨과 연결선 여백 기준으로 계산해 내부 왼쪽 여백을 최소화함

- 과학·경제 사건에 1830~1870년 철도 보급과 1840~1880년 사진기 보급을 추가함

- 사조 탭 전용 변경을 점검해 공용 atlas 스크롤·축·사건 스타일을 원래값으로 복구하고 movement-popup 범위로 분리함
- 기간 사건 색 순서가 1950년 이후 공통 구간에서도 이어지도록 보완하고 탭 작성 규칙에 범위·검증 기준을 정리함

## 프로젝트 점검

- 사조 HTML 14개에 남아 있던 base64 인라인 이미지 45개를 `data/미술사조/images/` 로컬 파일로 분리하고 문서 기준 상대 경로로 교체함
- 사조 HTML 검증에서 `data:image` 인라인 이미지와 누락된 로컬 이미지 경로를 실패로 잡도록 `tools/validate-movement-links.js`를 보강함
- 사조 HTML 작성 규칙에 base64 인라인 이미지를 금지하고 로컬 이미지 파일로 분리한다는 기준을 추가함
- 10MB를 초과하던 티에폴로·카리에라 썸네일 2개를 PNG 표시용 파일로 변환하고 작품 데이터 참조를 갱신함

## 공통 탭 구조

- 모든 왼쪽 사이드바에 우상단 패널형 아이콘 토글을 추가해 사이드바를 감추고 본문을 남은 폭 전체로 확장할 수 있게 함
- 접힌 상태에서는 화면 좌상단에 복원 토글만 남기고, 사이드바 표시 상태를 각 브라우저 탭에서 독립적으로 유지함
- 공통 및 각 탭 작성 규칙에 사이드바 보이기·감추기 토글과 탭별 독립 상태 기준을 추가함

## 프런트엔드 코드 구조

- `app.js`를 공통 상태·데이터 처리, 화가·작품 화면, 사조·국가별 화면, 상세 보기, 초기화 파일로 분리하고 기존 실행 순서를 유지함
- 서버의 정적 파일 허용 목록에 분리한 앱 스크립트를 추가함

## 서버 코드 구조

- `server.js`에서 외부 데이터 조회·화가 저장·썸네일 처리를 `server-data.js`로, 사조 문서·이미지 업로드·정적 파일 처리를 `server-content.js`로 분리함
- 서버 진입점에는 인증, 규칙 점검, 라우팅만 남기고 기존 API 경로와 인증 순서를 유지함
- 규칙 점검이 분리된 앱·콘텐츠 모듈의 사조 분류 기준을 확인하도록 갱신함

## 로그인 진입

- `?login=1`로 연 화면에서는 탭 세션뿐 아니라 공유 관리자 세션도 지워, 실행 파일을 다시 열 때 로그인 화면을 건너뛰지 않게 함
- 공용 새 탭의 첫 데이터 렌더링이 끝날 때까지 기본 화가 사이드바와 탭 이동을 숨겨 다른 탭에서의 화면 깜빡임을 제거함

## 분할 후 전수 점검

- 화가 목록 국가 아이콘·사조 필터·사조 분류 규칙 검사가 더 이상 축소된 `app.js`만 읽지 않고 분리된 전체 앱 모듈을 확인하도록 수정함
- 규칙 점검 보고서가 실제 코드 소유 파일인 `app-core.js`, `app-artists.js`, `server-content.js`를 가리키도록 정정함
- 공용 탭 작성 규칙에 앱·서버 모듈 책임, 로딩 순서, 분할 뒤 규칙 검사 대상 갱신 기준을 기록함
- `npm test`의 프로젝트 건강검사에 앱 스크립트 로딩 순서, 정적 파일 허용 목록, 서버 규칙 검사의 전체 앱 모듈 대상 여부를 추가함

## 성능·데이터 구조

- 화가 목록 초기 로딩을 data/artists-index.json 인덱스로 분리하고, 화가 선택 시 /api/artists/:id 상세 데이터를 불러오도록 변경함
- 서버 저장 시 아직 상세를 열지 않은 화가의 작품 목록을 기존 원본에서 보존하고, 저장 뒤 인덱스를 자동 재생성하도록 처리함

- 화가·화가 리스트 화면이 전체 작품 데이터에 의존하는 기존 기능을 확인해, 초기 지연 로딩 전환은 보류하고 전체 데이터 로딩으로 복구함. artists-index.json과 상세 API는 향후 단계적 전환용으로 유지함

## 화가 리스트 탭

- 기본 선택 국가를 네덜란드·덴마크·독일·벨기에·스페인·영국·오스트리아·이탈리아·프랑스로 바꾸고, 기존 저장 선택과 구분하는 v2 기본값을 적용함
- 가로 시간축 기본 맞춤 폭은 유지한 채, 기본 세로 화면에서 사조 행 약 18개가 보이도록 화가 리스트 전용 세로 배율을 조정함

- 기본 선택 국가에 이미 있던 독일은 유지하고 러시아를 추가해, 10개국의 동시대 사조·화가 비교 화면으로 구성함

- 기본 선택 국가에 스위스를 추가해 취리히 다다를 포함한 국제 전위미술 교류를 기본 비교 범위에 반영함

- 기본 세로 화면에 보이는 사조 행 수를 약 18개에서 약 12개로 줄이고, 나머지는 세로 스크롤로 보도록 조정함

- 사조 고정 열 글자의 비균등 확대 보정을 실제 화면 배율 기준으로 바꾸고 제목·보조 글자 크기를 낮춰 일반적인 글자 비율로 보이게 함
- 모든 화가 이름 상자의 공통 높이와 글꼴을 중심 기준으로 78%로 줄여, 생애 위치는 유지하면서 상자 사이 여백을 확보함

- 화가 이름 상자 안에서 activeFrom부터 등록 작품의 가장 늦은 제작 연도까지를 연한 하늘색으로 표시해 독립적 활동 시작과 마지막 등록 작품 시기를 구분함
