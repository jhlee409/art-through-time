# 변경사항 2026-08-30

## 화가 리스트 성능

- 화가 리스트 탭의 화가 이름 박스를 숨김 DOM 측정·복제 없이 계산된 좌표로 바로 오버레이 렌더링하도록 개선

## 국가별 미술 확대창

- 사조 박스 더블클릭 확대창의 폭을 화면 95%로 자동 조정하고, 확대창 안 대표작 이미지가 카드 높이의 95%를 차지하도록 조정

- 사조 확대창을 화면 세로 가운데 정렬하고, 이미지 더블클릭 확대 박스를 화면 90% 맞춤·전체 표시·드래그 이동 전용으로 변경

## 화가 리스트 UI

- 화가 리스트 탭 오른쪽 세부 사조 박스 제목 폰트를 기존 7.2px에서 1.3배인 9.36px로 확대

## 화가 및 작품 탭

- 화가 목록의 기본 정렬을 이름 오름차순으로 변경.
- 대표작 표시 토글과 화가/작품 유튜브 링크 저장 시 예약 저장과 즉시 저장이 겹치지 않도록 관리자 저장 흐름을 직렬화.

- 여러 탭에서 관리자 로그인이 갱신된 뒤에도 화가/작품 저장 요청이 최신 공유 토큰을 사용하도록 보강.

- 한 탭의 관리자 로그인이 다른 탭 세션을 무효화하거나, 오래된 탭이 최신 공유 세션을 지우던 문제를 수정.

- 화가 자료 저장 서비스의 누락된 관리자 이메일 정규화 함수를 복구해 `normalizedEmail is not defined` 422 오류를 수정.

- 화가 선택 시 전체 자료를 저장하던 동작을 제거하고, 링크·대표작 설정을 원본 작품 목록을 보존하는 부분 저장 API로 분리.

- 화가 및 작품 탭의 작품 이미지 더블클릭 확대를 화면 90% 비율 맞춤 박스로 변경하고, 좌측 하단 작품 정보와 3배 확대·드래그 이동을 추가.

- 확대 이미지의 3배 기능을 커서 추적형 원형 돋보기로 변경하고, 닫기 아이콘 대신 이미지 더블클릭으로 닫도록 조정.

- 모네를 포함한 모든 화가 연표에 같은 작품 확대·원형 돋보기 동작을 적용하고, 다른 탭에는 연결되지 않도록 범위를 화가 연표 패널로 한정.

- 국가별 미술의 사조 확대창과 이미지 확대창 왼쪽 아래에 화가명·작품명·연도를 표시하고, 사조 확대창은 빈 공간 더블클릭, 이미지 확대창은 이미지 더블클릭으로 닫도록 변경.

- 국가별 미술 2단계 이미지 확대창의 드래그 포인터 캡처 때문에 이미지 더블클릭 닫기가 누락되던 문제를 수정.

- 로그인 화면의 `건너뛰기` 버튼 이름을 `읽기 전용`으로 변경하고 관련 안내 문구를 일치시킴.

- 기법·용어 설명 제목 옆 원형 자료 링크 번호를 우클릭하면 관리자용 삭제 메뉴가 열리고 해당 링크를 삭제할 수 있도록 추가.

- 화가·작품, 기법·용어, 사조 설명의 모든 `+` 자료 주소 입력창에 `강조` 체크박스를 추가하고, 강조해 저장한 원형 링크 번호의 원과 숫자를 기본 크기의 두 배로 표시.
