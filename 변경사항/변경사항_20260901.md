## 큰 코드 파일 동명 폴더 분할

- `app/app-core.js`, `app/app-artists.js`, `app/app-atlas.js`, `app/app-detail.js`의 기능을 각각 확장자를 뺀 동명 폴더 아래 4~8개 파일로 분할하고, 원본 경로는 짧은 호환 진입점으로 유지했다.
- `server-content.js`를 `server-content/` 아래 정적 경로, 문서 표현, 화가 연결, 저장, 업로드, 섹션 링크 모듈로 나눴다. 이 과정에서 로컬 이미지 업로드가 내보내지 않은 `thumbnailLocation`, `makePngUnderStorageLimit`를 참조하던 누락도 수정했다.
- `extras.css` 분할은 일부 실행 환경에서 `@import` 하위 경로가 차단되어 전체 화면 스타일이 빠지는 문제가 확인되어 분할 직전의 단일 파일로 복원했다.
- 공통 작성규칙에는 큰 JavaScript 파일의 추출 파일을 반드시 `원본 파일명(확장자 제외)/` 폴더에 저장하도록 명시하고, 공통 `extras.css`는 단일 파일로 유지하도록 예외를 기록했다.
- 독립 사조 HTML은 자체 완결 문서 계약을 유지해야 하므로 분할하지 않았다. 대형 상수 데이터가 중심인 일회성 시드·복구 도구도 실행 코드 책임이 섞인 파일이 아니어서 보존했다.
- 검증: `npm run test:deep`, `npm run research:check`, `git diff --check`, 포트 4174의 전체 HTTP 검사 통과. 연결된 브라우저가 없어 자동 화면 캡처는 수행하지 못했다.
