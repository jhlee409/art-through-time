## 큰 코드 파일 분할 복원

- `app/app-core.js`, `app/app-artists.js`, `app/app-atlas.js`, `app/app-detail.js`를 분할 직전의 단일 파일로 복원하고 하위 조각 파일과 호환 진입점을 제거했다. 고전 스크립트를 파일 단위로 나누면서 뒤 파일의 함수 선언이 앞 파일 초기화보다 늦게 실행되어 로그인이 시작되지 않던 문제를 해소했다.
- `server-content.js`도 단일 파일로 복원하고 `server-content/` 모듈 폴더를 제거했다. 가변 서버 포트와 업로드 연결에 필요한 이후 개선은 `server.js`에 유지했다.
- `extras.css`는 하위 `@import` 경로 차단으로 전체 화면 스타일이 빠지지 않도록 분할 직전의 단일 파일을 유지한다.
- 분할 소스를 조합하던 `tools/source-bundles.js`를 제거하고 프로젝트·연구·사조 동기화 검사가 실제 단일 원본 파일을 직접 읽도록 복원했다.
- 독립 사조 HTML은 자체 완결 문서 계약을 유지해야 하므로 분할하지 않았다. 대형 상수 데이터가 중심인 일회성 시드·복구 도구도 실행 코드 책임이 섞인 파일이 아니어서 보존했다.
- 검증: `npm run test:deep`, `npm run research:check`, `git diff --check` 통과. 서버 재시작 뒤 단일 앱 스크립트 응답 200, 관리자 로그인 200, 세션 확인 204를 확인했다. 전체 HTTP 검사는 OneDrive에서 열 수 없는 기존 이미지 `data/images/artist-Q7814/wikidata-Q2016193.jpg`의 `EPERM`으로 이미지 단계에서 중단됐다. 연결된 브라우저가 없어 자동 화면 캡처는 수행하지 못했다.
