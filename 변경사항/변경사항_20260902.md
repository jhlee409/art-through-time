- 화가 해설 편집 저장본을 읽기 화면에서 제한된 HTML 문서형 스타일로 렌더링하고, 제목·인용·강조·표·외부 이미지 자리표시 표시 규칙을 추가

- 화가 해설 흐름을 편집·스크립트 입력·변환으로 분리하고, OpenAI API는 저장된 해설과 유튜브 스크립트의 문서형 변환에서만 사용하도록 변경

- 문서형 변환에서 기존 해설과 유튜브 스크립트를 통합하지 않고 입력 블록 순서와 경계를 보존하도록 변경

- 화가 해설 입력 단계에 md 업로드 버튼을 추가하고, 일반 텍스트·md·유튜브 스크립트 입력 후 마지막 변환에서만 API를 사용하도록 흐름 정리

- 화가 해설에 스크립트 요약 버튼을 추가하고, 긴 스크립트는 요약본만 해설 블록으로 저장한 뒤 최종 변환에서 저장된 입력 블록만 문서형으로 다듬어 저장하도록 변경

## 보안
