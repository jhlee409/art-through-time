- 다운로드용의 앙겔리카 카우프만 작품 14점을 작품 연표에 추가하고 그라쿠스 형제의 어머니 코르넬리아의 기존 로컬 이미지를 교체

- 카스파 다비드 프리드리히의 누락된 《안개 바다 위의 방랑자》(1818) 작품 레코드를 기존 로컬 이미지와 연결하고 독일 낭만주의 정본 대표작·화가 연표 대표작 표시를 복구

- 카스파 다비드 프리드리히 레코드에 병합돼 있던 에두아르 마네 작품 66점을 별도 마네 화가 레코드로 분리하고, 프리드리히의 독일 낭만주의 작품 연표·프로필을 복구

- 프리드리히·마네가 병합된 생성 원본을 분리하면서 각 화가의 누락된 본인 작품과 기존 로컬 이미지 연결을 복구

- 생성 원본 QID·화가 ID와 generated 작품 ID의 소유 관계를 자동 검사하는 validate-artist-ownership 도구를 추가하고 프로젝트 전체 점검에 포함

- 생성 원본 스냅샷 밖의 작품 19점을 Wikidata 제작자(P170) QID로 전수 대조해 소유 검증 기록을 추가하고, 향후 같은 유형의 작품은 검증 기록 없이는 통과하지 못하도록 강화

## 미술 사조의 이해

- 신고전주의의 앙겔리카 카우프만 선정 이유를 가정적 소재 확장이 아닌 여성 역사화가로서의 지속적 신고전주의 역사화 기여로 정정

- 신고전주의의 앙겔리카 카우프만 대표작을 그라쿠스 형제의 어머니 코르넬리아에서 파리스의 심판으로 교체하고 화가 정본·대표작 카드·표를 동기화

- 신고전주의에 나폴레옹 제정기의 이미지 정치를 독립 사례로 추가하고, 다비드·앵그르·카노바의 로컬 작품 5점으로 영웅화·의례화·통치자상·주권 상징·고전적 신격화를 비교하도록 보강
