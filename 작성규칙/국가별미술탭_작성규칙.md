# 국가별 미술 탭 작성 규칙

[공통 탭 구조](공통_탭구조.md)를 함께 적용한다.

- `?countryArt=1`에서 한 국가의 1400~1950년 사조 변천을 단일 연표로 표시한다.
- 기본 배율은 선택 기간과 모든 행이 오른쪽 화면 안에 맞고 빈 공간이 남지 않게 계산한다. 가로 스크롤은 사용자가 확대한 경우만 허용한다.
- 대표작은 사조 HTML의 마지막 심화 카드만 읽고 카드 DOM 순서를 유지한다. 이 탭에서 작품·이미지·카드를 직접 추가하지 않는다.
- 사건은 `data/country-art-events.json`, 사조 태동 배경은 `data/country-movement-backgrounds.json`에 분리한다.
- 검증: `node --check app.js`, `node tools/check-project-health.js`.
