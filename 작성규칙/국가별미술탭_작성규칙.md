# 국가별 미술 탭 작성 규칙

[공통 탭 구조](공통_탭구조.md)를 함께 적용한다.

- `?countryArt=1`에서 한 국가의 1400~1950년 사조 변천을 단일 연표로 표시한다.
- 기본 배율은 선택 기간과 모든 행이 오른쪽 화면 안에 맞고 빈 공간이 남지 않게 계산한다. 가로 스크롤은 사용자가 확대한 경우만 허용한다.
- 왼쪽 국가 선택 사이드바와 막대 표 안의 사조명 라벨 열은 막대 영역 확보를 위해 일반 사이드바·기존 라벨 열보다 10% 좁게 유지한다.
- 사용자가 휠로 확대하거나 가로 이동해도 왼쪽 국가명·`사조`·`사건`·사조명 열은 화면 왼쪽에 고정해 현재 행 맥락을 잃지 않게 한다.
- 고정용 복제 열은 기본 배율이나 가로 스크롤이 0인 상태에서는 숨기고, 원래 왼쪽 열이 시야에서 벗어나는 가로 이동 상태에서만 표시한다.
- 고정용 복제 열은 JS의 X축 이동 보정으로 따라오게 하지 않고, 스크롤 영역의 왼쪽 경계에 CSS 고정 배치해 확대·축소·드래그 중에도 흔들리지 않게 한다.
- 대표작은 사조 HTML의 마지막 심화 카드만 읽고 카드 DOM 순서를 유지한다. 이 탭에서 작품·이미지·카드를 직접 추가하지 않는다.
- 사건은 `data/country-art-events.json`, 사조 태동 배경은 `data/country-movement-backgrounds.json`에 분리한다.
- 모든 당사국 전쟁을 나열하지 않고, 미술 후원·제도·작가 이동·국가 이미지·사조 태동에 직접 영향을 준 전쟁만 `eventKind: "war"`로 표시한다.
- 모든 사건의 이름·연도·설명 라벨은 시작점을 기준으로 왼쪽에 둔다.
- 전쟁 사건은 기간선을 가리지 않도록 이름 라벨을 기간선 왼쪽에 둔다. 해당 국가가 승전국이면 `countryOutcome: "victory"`로 붉은 굵은 실선, 패전국이면 `countryOutcome: "defeat"`로 초록 굵은 실선, 내전·복합전쟁·결과 판정이 어려운 사건은 `countryOutcome: "unclear"`로 검은 굵은 실선을 쓴다.
- 사건 레일은 216px 높이를 기준으로 하며, 사건·범례·코너 글자는 초기 소형 표시보다 1.5배 크게 둔다.
- 맨 위 연도칸은 76px 높이와 20px 글자의 세기 박스로 표시한다. `18세기`처럼 간략 표기하고, 각 세기 라벨은 해당 세기 영역 가운데 정렬한다.
- 세기 경계마다 수직선을 두고, 세기 박스는 하나 건너 옅은 복숭아색 배경을 넣는다.
- 검증: `node --check app.js`, `node tools/check-project-health.js`.
