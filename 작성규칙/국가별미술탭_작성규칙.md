# 국가별 미술 탭 작성 규칙

## 사조 분류 원칙

- 국가별 미술의 국가 선택은 비교 범위일 뿐 사조 분류 기준이 아니다. 같은 정본 부모 사조에 속한 지역적 수용은 화면에서 부모 사조명 하나로 표시하고, 국가·후원·제도 차이는 작품 설명과 배경 패널에서 다룬다.
- 이 탭은 화가 리스트와 달리 사조 안의 하부 화파·시대 단계 상자를 만들지 않는다. 명확한 화파·계보도 상위 사조의 작품 행 안에서 활동 맥락으로만 보여 준다.

[공통 탭·전용 HTML 작성 규칙](새탭_template_작성규칙.md)을 함께 적용한다. 이 탭이나 국가별 사조 막대·대표작 표시 흐름을 수정하기 전에는 README의 `작업 전 필수 작성규칙` 절차와 이 문서를 먼저 확인한다.

- `?countryArt=1`에서 한 국가의 1400~1950년 사조 변천을 단일 연표로 표시한다. 선택 국가의 `data/art-movements.json`에 등록된 항목은 정본 부모 사조로 정규화해 한 행씩 표시한다. 같은 부모에 속하는 지역 전개·국가명 수용·학파·기관은 별도 막대가 아니며, 작품과 배경 설명의 역사적 맥락이다. 단, 후기 비잔틴·고딕처럼 `contextOnlyMovements`에 속한 이전 미술 참고 막대는 국가별 미술 탭의 정규 사조 행으로 표시하지 않는다.
- 기본 배율은 선택 기간과 모든 행이 오른쪽 화면 안에 맞고 빈 공간이 남지 않게 계산한다. 가로 스크롤은 사용자가 확대한 경우만 허용한다.
- 왼쪽 국가 선택 사이드바와 막대 표 안의 사조명 라벨 열은 막대 영역 확보를 위해 일반 사이드바·기존 라벨 열보다 10% 좁게 유지한다.
- 사용자가 휠로 확대하거나 가로 이동해도 왼쪽 국가명·`사조`·`사건`·사조명 열은 화면 왼쪽에 고정해 현재 행 맥락을 잃지 않게 한다.
- 고정용 복제 열은 기본 배율이나 가로 스크롤이 0인 상태에서는 숨기고, 원래 왼쪽 열이 시야에서 벗어나는 가로 이동 상태에서만 표시한다.
- 고정용 복제 열은 JS의 X축 이동 보정으로 따라오게 하지 않고, 스크롤 영역의 왼쪽 경계에 CSS 고정 배치해 확대·축소·드래그 중에도 흔들리지 않게 한다.
- 오른쪽 사조 밴드 사이의 행 구분선은 검은 실선으로 표시해 인접 사조가 명확히 분리되어 보이게 한다.
- 작품은 사조 HTML의 `data-art-atlas-representative-section="works"` 구역만 읽고, 같은 `developmentId`의 대표 화가 카드와 더 볼 화가 카드 DOM 순서를 모두 유지한다. 상단 도판이나 학습 길잡이 이미지는 가져오지 않으며 이 탭에서 작품·이미지·카드를 직접 추가하지 않는다.
- 정본 연결이 있는 사조 막대의 대표작 원본 문서는 표시 이름으로 추측하지 않고 `canonical.documentOwnerId`가 가리키는 부모 설명 문서를 먼저 사용한다. 표시 이름이 흡수형·지역 전개·학파 이름이어도 owner 문서의 대표작 카드 중 같은 국가에 해당하는 카드만 표시한다.
- 정본 연결이 있는 사조 막대는 owner 문서의 모든 국가 카드가 아니라, 막대의 `canonical.developmentIds`와 같은 대표작 카드만 읽는다. 같은 국가와 문서를 공유하는 다른 세부 사조 카드가 해당 막대에 섞이면 안 된다.
- 국가별 미술의 사조 막대 안 대표작 이미지는 작가 짧은 이름, 작품 제목, 연도만 캡션으로 표시한다. 카드 설명문과 선정 이유는 이 탭에 노출하지 않는다.
- 사조 막대를 더블클릭해 연 확대 창은 현재 화면 가로 폭의 95%로 자동 표시하고 화면 세로 가운데에 둔다. 확대 창 안의 각 대표작 이미지는 카드 높이의 약 95%를 차지하게 해 도판을 우선적으로 크게 보여준다.
- 사조 막대를 더블클릭해 연 확대 창 안에서는 대표작 이미지에 마우스를 올리는 것만으로 추가 확대 창을 띄우지 않는다. 확대 창 안의 이미지를 더블클릭하면 별도 이미지 박스를 연다. 두 확대 단계 모두 왼쪽 아래에 짧은 화가명·작품명·연도를 표시하며, 여러 작품이 있는 1단계 창의 정보줄은 커서가 올라간 작품 기준으로 갱신한다. 1단계 창은 작품 카드가 아닌 빈 공간을 더블클릭하면 닫고, 2단계 이미지 박스는 이미지 자체를 더블클릭하면 닫는다. 이미지 박스는 원본 비율을 유지한 채 가로 또는 세로 중 가능한 큰 쪽이 화면의 90%에 닿도록 자동 크기 조정하며, 이미지는 잘리지 않고 전체가 보여야 한다. 이 이미지 박스에는 크기 조절 손잡이를 두지 않고 드래그 이동만 제공한다.
- 표시 이미지는 사조 카드가 가리키는 `artistId + workId`의 `data/images/artist-*/` 정본 파일을 그대로 사용한다. 이 탭 전용 복사본을 만들거나 사조 설명 전용 도판으로 대신하지 않는다.
- 사조 대표작 카드의 이미지 경로가 바뀌면 국가별 미술 탭은 새 HTML/JSON 정본을 읽어 따라가야 하며, 이 탭 안에 이전 경로 보정이나 별도 복사본 참조를 추가하지 않는다.
- 국가·범주 판정은 카드 제목 문자열이나 국가 별칭으로 추측하지 않고 카드 묶음의 `data-art-atlas-development-id`, `data-art-atlas-category-id`, `data-art-atlas-country-ids`를 사용한다.
- `imageState="pending"` 또는 `다운로드 필요` 카드는 표와 화가 리스트에는 이름을 유지하지만 국가별 미술의 그림에는 표시하지 않는다. 표시 가능한 로컬 이미지가 하나도 없으면 다른 사조 작품을 대신 넣지 않고 `대표작 자료 없음` 또는 이미지 대기 상태를 표시한다.
- 사건은 `data/country-art-events.json`, 사조 태동 배경은 `data/country-movement-backgrounds.json`에 분리한다.
- 모든 당사국 전쟁을 나열하지 않고, 미술 후원·제도·작가 이동·국가 이미지·사조 태동에 직접 영향을 준 전쟁만 `eventKind: "war"`로 표시한다.
- 모든 사건의 이름·연도·설명 라벨은 시작점을 기준으로 왼쪽에 둔다.
- 전쟁 사건은 기간선을 가리지 않도록 이름 라벨을 기간선 왼쪽에 둔다. 해당 국가가 승전국이면 `countryOutcome: "victory"`로 붉은 굵은 실선, 패전국이면 `countryOutcome: "defeat"`로 초록 굵은 실선, 내전·복합전쟁·결과 판정이 어려운 사건은 `countryOutcome: "unclear"`로 검은 굵은 실선을 쓴다.
- 사건 레일은 216px 높이를 기준으로 하며, 사건·범례·코너 글자는 초기 소형 표시보다 1.5배 크게 둔다.
- 맨 위 연도칸은 76px 높이와 20px 글자의 세기 박스로 표시한다. `18세기`처럼 간략 표기하고, 각 세기 라벨은 해당 세기 영역 가운데 정렬한다.
- 세기 경계마다 수직선을 두고, 세기 박스는 하나 건너 옅은 복숭아색 배경을 넣는다.
- 추가 검증: `node tools/validate-country-art-data.js`, `node tools/validate-country-movement-development-dedup.js`, `node tools/validate-cross-tab-linkage.js`, `node tools/validate-movement-representatives.js`, `node tools/validate-movement-image-paths.js`, `node tools/validate-movement-links.js`. 정본 목표 36개 문서가 모두 등록된 뒤에는 `node tools/validate-movement-sync-v1-runtime.js`를 추가한다.
