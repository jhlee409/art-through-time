# 기법 및 용어 탭 작성 규칙

[공통 탭 구조](공통_탭구조.md)를 함께 적용한다.

- 이 탭은 사조 설명을 반복하는 곳이 아니라 초심자가 작품의 재료, 제작 방식, 빛·색채, 공간, 구도, 매체를 읽는 데 필요한 어휘를 보충하는 곳이다.

- 왼쪽에는 이름 표기, 제목, 검색·정렬·필터, 로그아웃을 유지한다.
- 사이드바 우상단의 아이콘 토글로 현재 브라우저 탭의 사이드바만 감추거나 보이게 한다. 접힘 상태는 다른 탭과 동기화하지 않는다.
- 기법과 전문 용어를 함께 다루며 검색은 즉시 필터링한다.
- 새 기법은 `data/techniques.json`에 고유 `id`, 도입 시기, 한·영 이름, 정의·설명, 태그, 참고 링크를 함께 등록한다. 검색어뿐 아니라 현재 선택된 분류 필터에서도 보이도록 최소 하나 이상의 공통 필터 태그(`제작 기법`, `빛·색채`, `공간·원근`, `구도·인체`, `매체·공예`, `장르·주제`)를 포함한다.
- 대표작을 넣을 수 있는 기법은 로컬 이미지와 작품명·작가·연도·매체가 확인된 예시를 최소 한 점 연결한다. 대표 이미지가 없으면 빈 `src`나 외부 이미지 URL을 만들지 않고 예시를 보류한다.
- `examples`의 이미지 경로는 실제 존재 여부를 확인한다. 기법 설명의 외부 자료는 화면 이미지가 아니라 제목 옆 자료 링크로만 남긴다.
- 예시가 `data/artists.json`에 등록된 화가 작품이면 `artistId + workId`와 `data/images/artist-*/` 정본 파일을 재사용한다. 기법 전용 폴더에는 같은 작품의 복사본을 만들지 않으며, `data/techniques/기법ID/`는 화가 연표에 연결되지 않는 기법 설명 전용 자산에만 사용한다.
- 관리자만 용어 삭제, 설명 제목 옆 자료 링크, 비교 기법 자료 링크를 편집한다.
- 새 기법 전용 자산은 `data/techniques/기법ID/` 아래 로컬 파일로 저장하며 외부 이미지 URL을 새로 만들지 않는다.
- 검증: `node --check techniques.js`, `npm test`, `git diff --check`.
