# 기법 및 용어 탭 작성 규칙

[공통 탭 구조](공통_탭구조.md)를 함께 적용한다.

- 왼쪽에는 이름 표기, 제목, 검색·정렬·필터, 로그아웃을 유지한다.
- 기법과 전문 용어를 함께 다루며 검색은 즉시 필터링한다.
- 관리자만 용어 삭제, 설명 제목 옆 자료 링크, 비교 기법 자료 링크를 편집한다.
- 새 자산은 `data/techniques/기법ID/` 아래 로컬 파일로 저장하며 외부 이미지 URL을 새로 만들지 않는다.
- 검증: `node --check techniques.js`, `node tools/check-project-health.js`.
