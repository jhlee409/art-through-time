# 미술사조 이해 탭 작성 규칙

[공통 탭 구조](공통_탭구조.md)를 함께 적용한다.

- 사조 비교 탭은 `?movementPopup=1`이며, 왼쪽에는 국가·역사 사건 제어, 오른쪽에는 1400년 이후 국가별 사조 비교를 둔다.
- 사조 비교의 시작 연도는 약 1400년으로 고정한다. 그 이전 전 기간을 축에 포함해 이후 시기의 가시 범위를 줄이지 않으며, 1400년 무렵까지 이어지는 후기 비잔틴 미술과 고딕 미술은 시작 경계에서 `이전 미술 참고` 막대로만 표시한다. 두 항목은 부모 사조로 등록하거나 국가별 미술·화가 리스트의 정규 사조 행으로 전달하지 않는다.
- 이전 시대의 비교 맥락으로만 쓰는 이름은 `data/art-movements.json`의 `contextOnlyMovements`에 기록한다. 이 목록은 사조 비교 탭에서는 설명 문서를 열 수 있는 참고 막대로 유지하되, 다른 탭의 부모·세부 사조 분류에서는 제외한다.
- 국가별 막대는 독립 사조뿐 아니라 지역적 전개·시대양식·학파·기관·상위 범주도 포함할 수 있다. 이 경우 `data/art-movements.json`의 `kind`에 학술적 유형을 기록해 같은 층위의 독립 사조로 오해되지 않게 한다.
- 별도 설명 HTML은 독자적 조형 언어, 제도·집단, 선언 또는 분명한 내부 분화가 있는 항목에 둔다. 한 국가에서의 수용·변형만을 가리키는 막대는 유지하되 상위 사조 문서의 `여러 국가에서의 전개`로 연결한다.
- 사이드바 우상단의 아이콘 토글로 현재 브라우저 탭의 사이드바만 감추거나 보이게 한다. 접힘 상태는 다른 탭과 동기화하지 않는다.
- 이 문서의 레이아웃·휠·드래그·사건 표시 규칙은 `movement-popup` 범위의 사조 탭에만 적용한다. `국가별 미술`, 화가 목록, 화가 연표의 공용 연표 스타일·휠·스크롤 동작은 바꾸지 않는다.
- 세로 시간축은 5년·10년·50년 숫자 눈금 대신 `18세기`처럼 세기 단위 박스로 표시한다. 세기 라벨은 해당 세기 높이의 가운데 정렬하고, 각 세기 경계마다 수평선을 둔다.
- 국가별 사조 막대 배경에도 세기 경계선을 이어 그리고, 세기 박스는 하나 건너 옅은 복숭아색 배경을 넣어 국가별 미술 탭과 같은 방식으로 읽히게 한다.
- 오른쪽 상단에는 기간 선택 슬라이더 박스를 두지 않는다. 사조 비교 영역은 저장된 이전 기간 선택값에 묶이지 않고 전체 기간을 표시한다.
- 오른쪽 사조 비교 영역은 탭 이동 영역 아래부터 화면 하단까지 남은 세로 공간을 모두 사용한다.
- 가로 드래그 중에도 사건 컬럼과 세기 표시 컬럼은 왼쪽에 고정해 항상 보이게 한다. 세기 표시 컬럼은 이전 대비 80% 폭을 유지하고, 사건 컬럼은 한 줄 라벨과 연결선 여백에 맞춰 계산한다.
- 오른쪽 위 컨트롤 영역에는 표시 밀도 슬라이더를 두지 않는다. 사조 비교 영역 위 마우스 휠은 `미술 사조의 이해` 탭 전용으로 세로 간격만 `0.5x~11.25x` 범위에서 확대·축소하며, 휠 한 단계의 확대 계수는 `1.15배`로 한다. 다른 탭의 휠 줌 방식과 통일하지 않는다.
- 사조 비교 영역의 빈 배경 드래그는 상하좌우 스크롤 이동으로 동작한다. 국가 제목의 드래그 정렬, 사조 막대 더블클릭, 역사 사건 클릭과 충돌하지 않게 예외 처리한다.
- 막대 한 번 클릭은 선택·강조, 더블클릭은 설명 문서 열기를 유지한다. 국가별 세부 사조가 별도 문서를 갖지 않으면, 사조 분류 규칙으로 연결되는 부모 사조의 저장 설명 문서를 우선 연다. 이 정규화가 실패한 경우에만 해당 사조명으로 백과사전 검색을 연다.
- 역사 사건 분류는 `사회·정치`, `종교·사상`, `과학·경제`, `미술사` 4개로 운영하고, 왼쪽 사건 분류 버튼은 한 줄에 4개를 배치한다. 인쇄·과학·산업·철도·사진기·경제·우주과학·페스트·팬데믹 사건은 `과학·경제`로 분리해 `사회·정치` 집중을 줄인다.
- 기간이 있는 역사 사건의 아래 연결선은 사조 탭에서만 사건 이름의 첫 글자 아래에서 시작해 기본 2px의 두 배인 4px로 표시한다. 전체 사조 연표에서 위에서 아래 순으로 세어 검정·빨강·파랑·초록을 반복 적용하며, 1950년 이후 공통 구간에서도 앞 구간의 색 순서를 이어 간다. 다른 탭의 사건 기간선에는 이 규칙을 적용하지 않는다.
- 사건 라벨의 수평 연결선은 사조 탭에서만 사건 컬럼과 세기 박스 사이의 왼쪽 여백까지만 표시하고, 세기 박스 내부로는 그리지 않는다.
- 사조 탭의 사건 라벨은 줄바꿈 없이 한 줄로 표시한다. 사건 컬럼은 가장 긴 라벨과 연결선 여백만 수용하도록 계산해, 컬럼 내부 라벨 왼쪽의 빈 공간을 최소화한다.
- 관리자만 역사 사건과 설명 문서 추가·교체·삭제를 할 수 있다.
- 사조 설명 HTML을 수정하면 [사조 HTML 작성 규칙](사조html_작성규칙.md)을 함께 확인한다.
- 저장된 사조 설명 HTML을 서버에서 동적으로 보강할 때는, 보강 함수가 사용하는 유틸리티·데이터 접근 함수를 콘텐츠 서비스 의존성으로 명시해 전달한다. 서버 모듈을 분리하거나 이 경로를 수정한 뒤에는 로컬 서버를 재시작하고 `index.json`에 등록된 모든 설명 문서 URL이 HTTP 200인지 확인한다.
- 검증: `node --check app.js`, `node tools/check-project-health.js`.
