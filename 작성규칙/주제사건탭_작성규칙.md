# 주제·사건 탭 작성 규칙

[공통 탭 구조](공통_탭구조.md)를 함께 적용한다.

- 이 탭은 반복되는 주제·도상·사건이 시대와 사조에 따라 어떻게 다르게 표현되는지 작품 비교로 이해하게 한다. 사조의 전체 연표나 화가 전기를 그대로 복제하지 않는다.

- 왼쪽에는 이름 표기, 검색·정렬, 목록, 로그아웃을 유지한다.
- 사이드바 우상단의 아이콘 토글로 현재 브라우저 탭의 사이드바만 감추거나 보이게 한다. 접힘 상태는 다른 탭과 동기화하지 않는다.
- 주제·사건과 연결 작품의 이미지는 로컬 파일만 사용한다. 외부 이미지 URL을 새로 추가하지 않는다.
- 원본은 `data/topics.json`, 표시 이미지는 `data/topic-images/`가 소유한다. 화가 작품 이미지를 연결할 때도 외부 URL을 복사하지 않고 확인된 로컬 파일과 작품 ID를 사용한다.
- 각 항목은 한·영 제목, 초심자가 비교할 핵심 질문 또는 설명, 연결 작품의 제목·화가·연도·표시 순서를 갖는다. 작품 수를 채우기 위해 주제와 관련 없는 예를 넣지 않는다.
- 관리자용 추가·교체·삭제는 인증과 로컬 저장 API를 거쳐야 한다.
- 검증: `node --check topics.js`, `npm test`, `git diff --check`.
