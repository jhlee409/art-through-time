# 화가 리스트 탭 작성 규칙

`화가 리스트` 탭은 국가별 사조 흐름을 화가 배치용 빈 연표로 쓰기 위한 전용 화면이다.

## 화면 구조

- 탭 URL은 `index.html?artistList=1`, 창 이름은 `artThroughTimeArtistList`를 사용한다.
- 왼쪽 사이드바 제목은 `화가 리스트`로 표시하고, 국가 선택 목록은 `국가별 미술` 탭과 같은 데이터를 사용한다.
- 오른쪽 연표는 `국가별 미술` 탭의 세기 축, 고정 사조 열, 확대·축소, 드래그 이동, 기본 비율 복귀 동작을 그대로 유지한다.
- 이 탭의 상단 탭 이동 버튼에는 자기 자신인 `화가 리스트` 버튼을 표시하지 않는다. 다른 탭에서는 `화가 리스트` 버튼을 제공한다.

## 사조 박스

- 사조 막대의 위치, 폭, 색, 행 높이는 `국가별 미술` 탭과 동일하게 계산한다.
- 사건 레일과 `사건` 왼쪽 칸은 표시하지 않는다.
- 각 사조 막대 안에는 작품 카드, 대표작 없음 문구, 사조 배경 `!` 버튼을 넣지 않고 빈 박스로 남긴다.
- 빈 박스라고 해도 세기 배경, 사조명 고정 열, 확대·드래그 기능은 깨지지 않아야 한다.

## 완료 전 확인

`node --check app.js`, `node --check techniques.js`, `node --check topics.js`, `node tools/check-project-health.js`를 실행해 탭 라우팅과 문법을 확인한다.
