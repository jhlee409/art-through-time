# 화가 리스트 탭 작성 규칙

## 화가 연표 변경 연쇄 갱신

- 화가 연표에 작품 이미지를 추가하거나 화가를 새로 등록하거나, 화가·작품의 이름, 생몰년, 주요 활동 지역, 사조, 작품 정보를 수정할 때는 같은 작업에서 화가 관계도 탭과 화가 리스트 탭의 데이터를 만들거나 보충한다.
- 화가 관계도는 확인 가능한 관계만 `data/artist-relations.json`에 추가·보완한다. 관계가 확인되지 않은 경우에는 추정 관계를 생성하지 않는다.
- 화가 리스트는 변경한 화가의 주요 활동 국가, 역사적 국가명의 현재 국가명 정규화, 사조, 생몰년과 사조 기간의 겹침을 다시 검증한다. `regions`에는 확인된 활동 국가를 시간순으로 기록한다. 주요 활동 국가는 국적·출생국이 아니라 해당 사조의 대표작과 양식적 전환이 이루어진 제작 국가를 우선한다. 일반 활동 지역의 마지막 항목과 다를 때는 `movementActivityCountry`에 사조별 대표 활동 국가를 명시한다.
- 유효한 화가가 해당 국가의 사조 행 부재로 목록에서 빠질 경우, 역사적 근거를 확인한 뒤 `data/art-movements.json`의 국가별 사조 행을 함께 보강한다. 근거가 부족하면 임의로 다른 국가 사조에 넣지 말고, 제외 사유와 추가 검토 필요성을 남긴다.

`화가 리스트` 탭은 국가별 사조 흐름을 화가 배치용 빈 연표로 쓰기 위한 전용 화면이다.
같은 시대와 인접 국가에서 어떤 화가들이 동시에 살아 있었는지 비교하는 것이 핵심 목적이다.

## 화면 구조

- 탭 URL은 `index.html?artistList=1`, 창 이름은 `artThroughTimeArtistList`를 사용한다.
- 왼쪽 사이드바 제목은 `화가 리스트`로 표시하고, 국가 선택 목록은 `국가별 미술` 탭과 같은 데이터를 사용하되 복수 선택 체크박스로 제공한다.
- 기본값은 전체 국가 선택, `1400~1950` 전체 기간이며, 세로 방향은 화면 맞춤값의 1.68배로 표시한다. 가로 막대 영역은 기본 상태에서 화면 안에 맞춰 가로 스크롤바를 표시하지 않고, 세로 스크롤로 이동한다. 사용자가 휠로 추가 확대하면 가로 스크롤을 허용한다.
- 오른쪽 연표는 `국가별 미술` 탭의 세기 축, 고정 사조 열, 커서 위치 중심 확대·축소, 드래그 이동, 기본 비율 복귀 동작을 그대로 유지한다. 세기 표기 줄은 막대 영역의 세로 이동과 무관하게 상단에 고정한다. 화가 리스트의 세기 박스 기본 높이는 `38px`(일반 막대 축의 절반), 세기 글자는 `14px`(기존의 70%)를 사용하며, 확대·축소해도 이 높이와 글자 크기를 바꾸지 않는다. 왼쪽 고정 사조 열의 사조명·국가·기간 글자와 상단 헤더 글자도 기본 화면에서 보이던 크기로 고정하고, 행의 위치와 높이만 연표 확대율을 따른다.
- 화가 리스트의 오른쪽 상단 고정 열은 별도의 국가명 셀을 두지 않고 `사조(선택 국가 n개)` 한 셀로 합친다. 이 셀의 높이는 세기 박스와 같은 `38px`로 맞춘다.
- 이 탭의 상단 탭 이동 버튼에는 자기 자신인 `화가 리스트` 버튼을 표시하지 않는다. 다른 탭에서는 `화가 리스트` 버튼을 제공한다.

## 사조 박스

- 사조 막대의 위치, 폭, 색, 행 높이는 `국가별 미술` 탭과 동일하게 계산한다.
- 선택된 여러 국가의 사조는 시작 연도순으로 배치한다. 단, `미술 사조의 이해` 막대를 만들 때 공통 사조로 둔 같은 이름의 사조는 한 행으로 합치고, 국가마다 새로 만든 세부 사조는 별도 행으로 추가한다.
- 별도 행으로 추가된 세부 사조도 `미술 사조의 이해`의 사조 표시 규칙과 필터 계층에서 부모 사조가 정해져 있으면 그 부모 사조 묶음에 붙여 배치한다. 정렬할 때 이 부모 사조 묶음 전체를 하나의 덩어리로 보고, 묶음 안에 본 사조 행이 있으면 본 사조 시작 연도를 묶음 위치 기준으로 삼는다. 본 사조 행이 없을 때만 묶음 안에서 가장 먼저 시작한 세부 사조 연도를 기준으로 삼는다.
- 사용자는 사조명 행을 드래그해 현재 화면의 사조 순서를 임시로 바꿀 수 있다. 이 순서는 로컬 저장소나 데이터 파일에 저장하지 않으며, 새로고침이나 국가 선택 조건 변경 뒤에는 기본 정렬로 돌아간다.
- 행 라벨에는 사조명과 함께 국가명·기간을 표시한다. 같은 이름의 공통 사조가 여러 나라에서 쓰이면 국가명은 `프랑스 외 3개국`처럼 요약할 수 있다.
- 사건 레일과 `사건` 왼쪽 칸은 표시하지 않는다.
- 각 사조 막대 안에는 작품 카드, 대표작 없음 문구, 사조 배경 `!` 버튼을 넣지 않는다.
- 각 사조 막대에는 해당 국가·사조에 매칭되고 생애가 사조 기간과 겹치는 화가를 생존기간 길이의 둥근 사각형 박스로 표시한다. 국가는 `movementActivityCountry`가 있으면 이를 우선하고, 없으면 `regions`의 마지막 주요 활동 지역 하나를 사용한다. 역사 국가명은 현재 국가명으로 정규화한 뒤 선택 국가와 매칭한다. 박스 안에는 화가 이름을 넣고, 클릭하면 `화가 및 작품` 탭의 해당 화가 연표로 이동한다.
- 화가 박스는 같은 줄에서 시간 구간이 겹치지 않도록 패킹한다. 배치 계산은 생존기간의 시작 좌표를 기준으로 하되, 화면상 세로 위치는 출생년 목록 정렬이 아니라 겹치지 않는 가장 위쪽 빈 줄을 찾는 방식으로 정한다.
- 사조보다 생존기간이 긴 화가는 예외 박스로 표시할 수 있으며, 이 경우 생애 구간이 사조 막대 밖으로 일부 이어져 보일 수 있다.
- 생애 기간을 나타내는 가로 폭은 화가별로 유지한다. 세로 이름 상자 높이와 글자 크기는 전체 화면의 모든 사조 행에서 가장 낮은 이름 상자 값으로 통일한다. 공통 높이를 임의로 키우거나 행별 가용 공간에 따라 개별적으로 줄이지 않으며, 이 기준값이 모든 패킹 줄에 들어가도록 배치한다. 기본 전체 보기에서는 구조를 우선하고, 이름 판독은 확대 상태를 기준으로 한다.
- 화가 이름 판독성을 위해 `화가 리스트` 탭의 확대는 가로·세로 1:1 비율을 쓰지 않는다. 기본 배율 이후에는 가로 확대 한계를 `2.25x`로 두고, 세로 확대 증가분은 기존 비균등 확대보다 3배 크게 적용한다. 화가 이름 상자의 왼쪽과 오른쪽은 시간축의 출생·사망 좌표를 항상 그대로 따라야 한다. 각 상자의 높이·행 안쪽 위치·상자 사이 간격·마지막 상자 아래 여백은 해당 사조 행의 세로 확대율과 같은 비율로 계산한다. 글자는 가로·세로 같은 비율을 유지하며 각 이름 상자의 실제 높이 변화율과 같은 비율로 확대·축소한다.
- 화가 이름 박스의 배경색은 흰색, 테두리는 검은색 `1px` 실선으로 통일한다. 사조보다 생애가 긴 예외 박스는 필요한 경우 툴팁으로만 구분한다.
- 빈 박스라고 해도 세기 배경, 사조명 고정 열, 확대·드래그 기능은 깨지지 않아야 한다.

## 고정 회귀 방지 규칙

- 전체 화면의 모든 화가 이름 상자는 가장 낮은 이름 상자의 높이와 글꼴 크기를 공통 기준으로 사용한다. 이 기준은 기존에 확정된 요구사항이므로 후속 작업에서 다시 협의하거나 다른 크기 규칙과 혼합하지 않는다.
- 패킹, 확대·축소, 사조 행 높이, 국가 선택, 드래그 정렬을 수정할 때도 행별 높이 보정, 개별 상자 축소, 임의의 추가 확대를 넣지 않는다.
- 화가 리스트를 수정한 작업의 완료 전에는 전체 사조 행에서 이름 상자 높이와 글꼴 크기가 같고, 확대·축소 후에도 같은 비율로 변하는지 확인한다.

## 완료 전 확인

`node --check app.js`, `node --check techniques.js`, `node --check topics.js`, `node tools/check-project-health.js`를 실행해 탭 라우팅과 문법을 확인한다.
