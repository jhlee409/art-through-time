# 화가 리스트 탭 작성 규칙

[공통 탭 구조](공통_탭구조.md)를 함께 적용한다.

## 화가 연표 변경 연쇄 갱신

- 화가 연표에 작품 이미지를 추가하거나 화가를 새로 등록하거나, 화가·작품의 이름, 생몰년, 주요 활동 지역, 사조, 작품 정보를 수정할 때는 같은 작업에서 화가 관계도 탭과 화가 리스트 탭의 데이터를 만들거나 보충한다.
- 화가 관계도는 확인 가능한 관계만 `data/artist-relations.json`에 추가·보완한다. 관계가 확인되지 않은 경우에는 추정 관계를 생성하지 않는다.
- 화가 리스트는 변경한 화가의 주요 활동 국가, 역사적 국가명의 현재 국가명 정규화, 사조, 생몰년과 사조 기간의 겹침을 다시 검증한다. `regions`에는 확인된 활동 국가를 시간순으로 기록한다. 주요 활동 국가는 국적·출생국이 아니라 해당 사조의 대표작과 양식적 전환이 이루어진 제작 국가를 우선한다. 일반 활동 지역의 마지막 항목과 다를 때는 `movementActivityCountry`에 사조별 대표 활동 국가를 명시한다.
- 유효한 화가가 해당 국가의 사조 행 부재로 목록에서 빠질 경우, 역사적 근거를 확인한 뒤 `data/art-movements.json`의 국가별 사조 행을 함께 보강한다. 근거가 부족하면 임의로 다른 국가 사조에 넣지 말고, 제외 사유와 추가 검토 필요성을 남긴다.
- 사조 설명 HTML의 `여러 국가에서의 전개` 표에서 국가·지역, 세부 사조, 기간, 대표 화가를 변경하는 작업은 화가 리스트의 연쇄 갱신 작업이다. `data/art-movements.json`의 세부 사조 행과 `data/artists.json`의 활동 국가·사조·세부 사조·활동 기간을 같은 작업에서 맞춘 뒤, 선택 국가 화면에서 세부 사조 상자와 해당 화가 이름 상자가 표와 일치하는지 확인한다. 표의 대표 화가라는 이유만으로 근거 없는 국가·사조·기간 배정을 만들지 않는다.

`화가 리스트` 탭은 국가별 사조 흐름을 화가 배치용 빈 연표로 쓰기 위한 전용 화면이다.
같은 시대와 인접 국가에서 어떤 화가들이 동시에 살아 있었는지 비교하는 것이 핵심 목적이다.

화가 리스트 오른쪽 화면의 정본은 각 부모 사조 설명 HTML의 `여러 국가에서의 전개` 표다. 표 행의 `developmentId`가 세부 사조 상자를, `categoryId`가 정본 표시명을, `countryIds`가 표시 국가를, 대표 화가 링크 ID와 순서가 화가 이름 사각형을 결정한다. `data/art-movements.json`의 각 막대는 `canonical.parentId`, `documentOwnerId`, `categoryIds`, `developmentIds`로 이 행을 직접 가리키며 문자열 이름이나 국가 별칭으로 행을 추측하지 않는다. 사조 설명 저장 신호를 받으면 문서 캐시와 ID 맵을 비우고 최신 표에 맞춰 다시 그린다.

## 화면 구조

- 탭 URL은 `index.html?artistList=1`, 창 이름은 `artThroughTimeArtistList`를 사용한다.
- 왼쪽 사이드바 제목은 `화가 리스트`로 표시하고, 국가 선택 목록은 `국가별 미술` 탭과 같은 데이터를 사용하되 복수 선택 체크박스로 제공한다.
- 사이드바 우상단의 아이콘 토글로 현재 브라우저 탭의 사이드바만 감추거나 보이게 한다. 접힘 상태는 다른 탭과 동기화하지 않는다.
- 기본 선택 국가는 네덜란드, 덴마크, 독일, 벨기에, 스페인, 영국, 오스트리아, 이탈리아, 프랑스, 러시아, 스위스이며, 기간은 `1400~1950` 전체로 둔다. 이 구성은 서유럽·중부유럽의 주요 제작·유학·전시 네트워크, 러시아 전위미술, 취리히 다다의 국제 교류를 비교하는 기본값이고, 북유럽·미국 등은 필요할 때 추가 선택한다.
- 기본 화면에서는 세기 축 아래 부모 사조 행 약 5개가 보이도록 세로 배율을 계산하고, 나머지 사조는 세로 스크롤로 본다. 세기별 가로 폭은 기본 맞춤 폭의 `1.3배`를 사용하며, 화면 밖 시간 구간은 기존 가로 스크롤과 드래그 이동으로 탐색한다.
- 오른쪽 연표는 `국가별 미술` 탭의 세기 축, 고정 사조 열, 커서 위치 중심 확대·축소, 드래그 이동, 기본 비율 복귀 동작을 그대로 유지한다. 세기 표기 줄은 막대 영역의 세로 이동과 무관하게 상단에 고정한다. 화가 리스트의 세기 박스 기본 높이는 `38px`(일반 막대 축의 절반), 세기 글자는 `14px`(기존의 70%)를 사용하며, 확대·축소해도 이 높이와 글자 크기를 바꾸지 않는다. 왼쪽 고정 사조 열의 사조명·국가·기간 글자와 상단 헤더 글자도 기본 화면에서 보이던 크기로 고정하고, 행의 위치와 높이만 연표 확대율을 따른다.
- 화가 리스트의 오른쪽 상단 고정 열은 별도의 국가명 셀을 두지 않고 `사조(선택 국가 n개)` 한 셀로 합친다. 이 셀과 사조 고정 열은 일반 국가별 미술 화면 폭의 60%를 사용한다. 이 셀은 오른쪽 세기 밴드와 같은 화면상 `38px` 높이·`14px` 글자 크기를 사용한다. 확대·축소 중에도 오른쪽 시간축과 왼쪽 고정 열 모두에 같은 역보정 원본 높이를 적용해, 두 영역의 하단 경계와 첫 사조 행 시작선이 항상 정확히 맞아야 한다.
- 이 탭의 상단 탭 이동 버튼에는 자기 자신인 `화가 리스트` 버튼을 표시하지 않는다. 다른 탭에서는 `화가 리스트` 버튼을 제공한다.

## 사조 박스

- 화가 리스트에서는 필터 계층의 부모 사조를 한 행으로 표시하고, 그 행 안에 부모 사조 설명 HTML의 `여러 국가에서의 전개` 표에 있는 선택 국가의 국가별·세부 사조를 모서리가 둥근 하위 상자로 시작 연도순으로 넣는다. 사조 탭의 국가별 사조 데이터가 더 많은 국가·흐름을 포함하더라도 화가 리스트에는 표 행이 있는 국가·세부 사조만 만든다. 상자의 기간 좌표만 동기화된 일반 사조 데이터에서 사용하며, 표에 없는 국가·세부 사조 상자와 선택하지 않은 국가의 상자는 만들지 않는다.
- 화가의 생애 이름 상자는 해당 하위 사조 상자에서 생성하되, 전체 생애 구간은 하위 상자 밖으로 계속 표시한다. 다만 하늘색 활동 구간은 `activeFrom`~마지막 등록 작품 연도를 해당 하위 사조 기간으로 잘라, 색칠된 부분 전체가 그 하위 상자 안에 들어가게 한다.
- 세부 사조 상자가 하나 이상 있는 부모 사조 행에서는 부모 사조의 기간 막대를 그리지 않고, 왼쪽 열의 부모 사조명만 묶음 제목으로 남긴다. 세부 사조가 없는 경우에만 부모 사조 막대를 기본 높이로 표시한다.
- 같은 부모 사조에 속한 세부 사조 상자는 모두 같은 바탕색을 사용한다. 부모 사조별 바탕색은 구분 가능한 여섯 가지 색을 화면의 부모 사조 순서대로 순환 적용한다.
- 사조의 가로 위치·폭은 `국가별 미술` 탭과 같은 국가별 사조 기간 기준으로 계산하되, 세부 사조 상자 색은 부모 사조별 공통색 규칙을 따른다. 부모 사조 행 높이는 동일하게 고정하지 않고, 선택된 세부 사조 상자와 그 안에 패킹된 화가 이름 상자의 줄 수로 자동 계산한다.
- 선택된 여러 국가의 사조는 부모 사조 묶음의 기준 시작 연도순으로 배치한다. 부모 사조 행 안의 하위 상자는 각 국가·세부 사조의 시작 연도순으로 배치한다.
- 사용자는 사조명 행을 드래그해 현재 화면의 사조 순서를 임시로 바꿀 수 있다. 이 순서는 로컬 저장소나 데이터 파일에 저장하지 않으며, 새로고침이나 국가 선택 조건 변경 뒤에는 기본 정렬로 돌아간다.
- 행 라벨에는 사조명과 함께 국가명·기간을 표시한다. 같은 이름의 공통 사조가 여러 나라에서 쓰이면 국가명은 `프랑스 외 3개국`처럼 요약할 수 있다.
- 사건 레일과 `사건` 왼쪽 칸은 표시하지 않는다.
- 각 사조 막대 안에는 작품 카드, 대표작 없음 문구, 사조 배경 `!` 버튼을 넣지 않는다.
- 각 하위 사조 상자에는 같은 `developmentId` 표 행의 대표 화가를 링크 순서대로 표시한다. 버전 1 정본 행은 국적·활동 국가·사조 문자열의 보조 메타데이터가 다르다는 이유로 대표 화가를 화면에서 제거하지 않으며, 이러한 불일치는 별도 검증 경고로 다룬다. 생애가 화면 기간과 겹치지 않는 경우만 현재 시간축에서 보이지 않을 수 있다. 박스 안 이름을 클릭하면 `화가 및 작품` 탭의 해당 화가 연표로 이동한다.
- 화가 박스는 같은 줄에서 시간 구간이 겹치지 않도록 세부 사조 상자 안에서 패킹한다. 배치 계산은 생존기간의 시작 좌표를 기준으로 하되, 화면상 세로 위치는 출생년 목록 정렬이 아니라 겹치지 않는 가장 위쪽 빈 줄을 찾는 방식으로 정한다.
- 사조보다 생존기간이 긴 화가는 예외 박스로 표시할 수 있으며, 이 경우 생애 구간이 사조 막대 밖으로 일부 이어져 보일 수 있다.
- 생애 기간을 나타내는 가로 폭은 화가별로 유지한다. 세로 이름 상자 높이와 글자 크기는 전체 화면의 모든 세부 사조에서 같은 공통값으로 통일하고, 필요한 패킹 줄 수만큼 세부 사조·부모 사조 행 높이를 늘린다. 기본 전체 보기에서는 구조를 우선하고, 이름 판독은 확대 상태를 기준으로 한다.
- 화가 이름은 이름 상자 안에서 항상 한 줄로 표시하며, 현재 공통 이름 상자 높이의 80%를 사용한다. 제목이 긴 경우에도 여러 줄로 바꾸지 않고 말줄임표로 처리한다.
- 같은 세부 사조 안에서 화가 이름 상자 줄 사이의 배치 간격은 `1px`로 촘촘하게 두며, 표시 단계에서도 상자 높이를 94%로만 줄여 간격이 과도하게 커지지 않게 한다. 첫 이름 상자 위와 세부 사조 상단 경계 사이 및 마지막 이름 상자 아래와 세부 사조 하단 경계 사이에는 모두 `12px` 여백을 둔다. 위·아래 여백은 서로 같고 이름 상자 사이 간격보다 조금 커야 한다.
- 화가 리스트의 이름 상자는 `화가 및 작품` 탭 왼쪽 목록에서 쓰는 축약 한글 이름(`artistListKoreanName`)을 동일하게 사용하며, 화면 언어 설정에 따라 영문명으로 바꾸지 않는다.
- 세부 사조 상자의 제목은 상자 내부를 차지하지 않는다. 상단 테두리선의 왼쪽에 배치하고, 글자 중앙이 테두리선 위에 오도록 배경색을 깔아 표시한다.
- 세부 사조 상자 내부에서 화가 이름 상자와 세부 사조 제목을 제외한 빈 공간을 더블클릭하면 읽기 전용의 이동·크기 조절 가능 창을 열어, 부모 사조 설명 HTML의 `여러 국가에서의 전개` 표에서 그 세부 상자의 선택 국가·지역에 해당하는 특징만 표시한다. 열린 창 자체를 더블클릭하면 닫는다. 창의 제목줄 드래그는 이동, 네 변·모서리 드래그는 가로·세로 크기 조절이며, 이 기능은 데이터나 설명 문서를 편집하지 않는다.
- 지역 특징 창은 로드한 문서의 같은 `developmentId` 행에서 특징 셀의 번호 제목·불릿 목록 등 원본 마크업을 표시한다. 편집 아이콘·입력칸·저장·취소 제어는 가져오지 않으며, 저장 신호를 받으면 ID 맵을 다시 읽는다.
- 지역 특징 창의 기본 가로 폭은 제목과 닫기 안내가 한 줄로 들어가는 데 필요한 폭으로 계산하고, 기본 세로 높이는 본문 약 10줄을 읽을 수 있게 한다. 화면 폭이 이를 수용하지 못할 때만 화면 안 폭으로 제한한다.
- 세부 사조 제목과 왼쪽 사조 열의 제목·보조 정보는 화가 이름 상자와 같은 `var(--sans)` 글꼴 계열을 사용한다. 사조 선택 열은 국가·기간 보조 정보 없이 제목만 한 줄로 표시하고, 세기 밴드와 정확히 같은 `700 14px/1 var(--sans)` 글꼴·크기를 사용한다. 비균등 확대된 사조 열에서도 글자 자체에는 가로·세로 역보정을 적용해 화가 이름처럼 정상 비율로 보이게 한다.
- 세기 구분선과 사조 행 경계선은 화가 리스트 탭에서 더 진한 색을 사용해 인접 세기·사조 행의 구획을 명확히 한다.
- 시간상 겹치는 세부 사조 상자 사이에는 `18px`의 세로 간격을 두어 상자 테두리·제목·화가 이름이 서로 붙지 않게 한다.
- 화가 이름 판독성을 위해 `화가 리스트` 탭의 확대는 가로·세로 1:1 비율을 쓰지 않는다. 기본 배율 이후에는 가로 확대 한계를 `2.25x`로 두고, 세로 확대 증가분은 기존 비균등 확대보다 3배 크게 적용한다. 화가 이름 상자의 왼쪽과 오른쪽은 시간축의 출생·사망 좌표를 항상 그대로 따라야 한다. 각 상자의 높이·행 안쪽 위치·상자 사이 간격·마지막 상자 아래 여백은 해당 사조 행의 세로 확대율과 같은 비율로 계산한다. 글자는 가로·세로 같은 비율을 유지하며 각 이름 상자의 실제 높이 변화율과 같은 비율로 확대·축소한다.
- 화가 이름 박스의 배경색은 흰색, 테두리는 검은색 `1px` 실선으로 통일한다. 사조보다 생애가 긴 예외 박스는 필요한 경우 툴팁으로만 구분한다.
- 화가 이름 상자 안에서는 `activeFrom`부터 현재 등록된 작품 중 가장 늦은 제작 연도(`yearEnd` 우선, 없으면 `year`)까지를 연한 하늘색으로 표시한다. 이 구간은 `독립적 활동 시작~현재 등록 작품의 마지막 제작 시기`를 뜻하며, 생애·사조 표시 범위 밖으로 넘지 않게 자른다.
- 사조 고정 열의 글자는 연표의 비균등 확대를 역보정해 가로·세로 비율이 같은 일반 글꼴로 보이게 하며, 행 안에서 과도하게 커지지 않도록 제목은 `14px`, 보조 정보는 `10px`를 기준으로 둔다.
- 모든 화가 이름 상자는 공통 높이를 유지하되, 표시 단계에서 각 상자의 가로 중심선을 기준으로 위·아래가 같은 비율로 확장한다. 현재 기준은 원본 `139.968px`을 표시 단계에서 80%로 처리한 화면상 약 `111.974px`이며, 부모 사조·세부 사조의 높이는 이 공통 상자 높이와 필요한 줄 수에 맞춰 자동으로 늘린다.
- 부모 사조에 표시할 화가 이름 상자가 하나도 없으면 세부 사조 상자를 만들지 않고, 화가 이름 상자 3개를 배치할 수 있는 높이를 그 부모 사조의 기본 높이로 사용한다.
- 빈 박스라고 해도 세기 배경, 사조명 고정 열, 확대·드래그 기능은 깨지지 않아야 한다.

## 고정 회귀 방지 규칙

- 전체 화면의 모든 화가 이름 상자는 정해진 공통 높이와 글꼴 크기를 사용한다. 이 기준은 기존에 확정된 요구사항이므로 후속 작업에서 다시 협의하거나 다른 크기 규칙과 혼합하지 않는다.
- 패킹, 확대·축소, 사조 행 높이, 국가 선택, 드래그 정렬을 수정할 때도 화가 이름 상자의 행별 높이 보정·개별 상자 축소·임의의 추가 확대를 넣지 않는다.
- 화가 리스트를 수정한 작업의 완료 전에는 전체 사조 행에서 이름 상자 높이와 글꼴 크기가 같고, 확대·축소 후에도 같은 비율로 변하는지 확인한다.
